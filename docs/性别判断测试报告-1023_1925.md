## 1. 结论

1. **不偏向男或女**：同一句话的女版本对 56/60、男版本对 54/60；认错成"女" 7 次、认错成"男" 6 次。错误男女两边几乎一样多。
2. **该认的都认出来了**：自称 36/36、确认 12/12（包括没带主语的"就是女孩子啦"、只回"是的"的确认）；问句 18/18 都没被当成自称——10/23 那次误判的两句（"你觉得我是男孩子还是女孩子呢""我可没说我是男生"）都判对了。
3. **错的都是同一种：从别的话往回推出另一个性别**：

| 对方这句 | 应该 | 模型答的 | 它的推法 |
|---|---|---|---|
| 我不是女生 / 我不是男生 | 否认 | 男 / 女（3 次都错） | 不是女生 → 那就是男生 |
| 我要是男生就好了 | 无 | 女（3 次） | 想当男生 → 那现在是女生 |
| 我和我女朋友去看电影了 | 无 | 男（3 次） | 有女朋友 → 是男生 |
| 下辈子想当女孩子 | 无 | 女（1 次） | 把愿望当成了自称 |

这类推法有时候猜得对，但对方并没有说，不该当成"自称"（会让她质疑一句"你说你是女生？"）。另外"我要是女生就好了"三次都判对了，"我要是男生就好了"三次都错，是同一种问题在两个版本上碰巧不一样，不是偏向。

## 3. 改了什么（第 2 轮）

`affection_turn.py` 的 `GENDER_JUDGE_PROMPT` 加一段：

> 只认对方**直接说出来**的自己的性别，不要从别的话往回推：
> - "我不是女生""我又不是男生"只说了不是什么，答"否认"，不要推成另一个性别（除非同一句里又直接说了"我是男生 / 女生"）；
> - "我要是男生就好了""下辈子想当女孩子""我女朋友 / 男朋友……"都推不出对方是什么性别，答"无"。

测试加 3 对，看会不会改过头：

- "我不是男生，我是女生"：同一句里直接说了，应该认出来；
- "作为一个女生，我觉得这不公平"：应该认出来；
- "我男朋友今天来接我"：不该认（和"女朋友"成对）。

现在一共 50 句 × 3 次 = 150 次调用，不到 1 分钱。
