# 伊蕾娜发表情包：功能方案

> 状态：已上线（v5，2026-09-26），代码在 `bot\plugins\roleplay_chat\stickers.py`，使用说明见部署指南 5.13。第 8 节的几项都已在真机上验证，正常使用。
> 目标：聊天时有一定概率用小号"收藏表情"里的伊蕾娜表情包表达情绪，可以跟在文字后面，也可以只发一张表情。

---

## 1. 已确认的决定

| 项 | 决定 |
|---|---|
| 表情来源 | 小号 QQ 的收藏表情（"爱心"里的），由你自己维护，只收藏伊蕾娜的表情 |
| 是否过滤非伊蕾娜表情 | 不过滤，收藏里的全部都用 |
| 出现频率 | 适中，约 15% 的回复带表情；同一个群至少隔 3 分钟才发一次 |
| 只发表情、不说话 | 要。但每次都先调模型看上下文，保证表情和话题对得上；不做免费的盲发 |
| 给消息贴 QQ 小表情（`set_msg_emoji_like`） | 这次先不做 |

---

## 2. 表情库：拉取与缓存

- **拉取**：调用 NapCat 的 `fetch_custom_face`（获取收藏表情），拿到收藏表情的地址列表。
- **时机**：启动时拉一次，之后每 6 小时一次；管理员发 `/表情 刷新` 时立刻拉。
- **本地缓存**：每张下载到 `bot\data\stickers\`，文件名用内容哈希，重复的只存一份。发送时用本地文件，不依赖 QQ 链接的有效期。
- **同步删除**：收藏里取消的表情，下次刷新时标记成"已移除"，以后不再发。本地文件保留，便于恢复。
- **发送格式**：图片消息段加 `sub_type=1`，让它在 QQ 里显示成表情样式（小图，不点开看大图）。**开发时要先实测**：如果 NapCat 不认这个字段，就退回普通图片发送。

---

## 3. 给每张表情打情绪标签

收藏表情本身没有名字，需要先"看懂"一次：

- 新表情入库时，交给 deepseek-flash 看一次（复用识图模块 `vision.py`），输出：
  - 1～2 个**情绪标签**，从固定词表里选；
  - 一句**描述**，包括配字，例如"戴帽子叉腰，一脸得意，配字'不愧是我'"。
- **情绪词表**（暂定 10 个，开发时可微调）：
  得意 · 嫌弃 · 无语 · 生气 · 开心 · 害羞 · 疑惑 · 委屈 · 震惊 · 敷衍
- 结果存进 `data\stickers\index.json`，之后不再重复看。每张约 0.1～0.2 分钱，一次性花费。
- 高峰时段不打标签，新表情等低峰时段再处理。

### 管理员指令（群里先 @ 她）

| 指令 | 作用 |
|---|---|
| `/表情 列表` | 列出所有表情的编号、标签、描述 |
| `/表情 3` | 把 3 号表情发出来看看 |
| `/表情 3 嫌弃 无语` | 手动改 3 号的标签（手动改过的，刷新时不会被覆盖） |
| `/表情 3 禁用` / `/表情 3 启用` | 停用或恢复某一张 |
| `/表情 刷新` | 立刻重新拉收藏 |
| `/表情 测试 嫌弃` | 按情绪挑一张发出来，用来检查挑选逻辑 |

## 4. 什么时候发、发哪张

### 4.1 决定"这一轮能不能发"（程序抽签，不花 token）

每次要回复时，程序先判断这一轮能不能带表情，以下条件都要满足：

1. 表情库里有可用表情；
2. 这个群距离上次发表情已过 3 分钟（`STICKER_MIN_INTERVAL=180`），私聊按人算；
3. 按关系抽签（见 4.4），基础概率 15%（`STICKER_PROB=0.15`）。

抽中了，才在这一轮的提示里告诉她"这次可以用表情"，并给出可用的情绪列表（**只列库里真的有的情绪**）。没抽中，提示里不出现表情相关内容，她也就不会用。

### 4.2 模型怎么表达（零额外调用）

抽中时，提示里允许她在回复末尾写一个标记：

```
你脑子没问题吧 [表情:嫌弃]
```

或者整条回复只写标记，表示只发表情：

```
[表情:得意]
```

程序截掉标记，再按情绪去库里挑一张。她也可以不用，觉得不合适就正常回文字。

**只发表情的比例**：原来"长短随机"里 30% 只回几个字的那一档，如果这一轮抽中了表情，会提示她"这次可以只甩一个表情"。

### 4.3 挑哪一张

- 在标签匹配的表情里随机挑；
- 同一个群（或私聊）最近发过的 5 张不选，都用过了再放开；
- 标签对不上（模型写了库里没有的情绪）：先试同义词（例如"开心"对"得意"），还是没有就只发文字，不硬凑。

### 4.4 和好感度的配合

| 档位 | 概率倍数 | 能用的情绪 |
|---|---|---|
| 讨厌 | ×0.5 | 只有嫌弃、无语、敷衍 |
| 陌生人 | ×0.7 | 除了害羞、委屈，其余都可以 |
| 熟人 | ×1.0 | 全部 |
| 很熟 | ×1.3 | 全部 |

### 4.5 斗图

群友发了她的表情包（5.11 已经能认出来），她要搭话时，这一轮表情概率提高到 50%，更容易回一张表情。这仍然走模型，保证回的情绪对得上图里的内容。

## 5. 发送与各机制的配合

- **顺序**：文字 + 表情时，先发文字（按现有分条规则），隔 1～2 秒再发表情。表情单独算一条，不引用原消息；只发表情时，如果中间有人插话，就引用原消息（和文字回复的规则一样）。
- **限额**：表情计入每小时限额（全局 60 条、每群 40 条）。限额只剩最后 1 条时就不发表情，留给文字。
- **高峰时段**：正经回复可以带表情（反正已经调了模型）；"在忙，晚点。"这类固定台词不变，不做免费的盲发。
- **记忆**：聊天记录里写成 `[发了表情：嫌弃（叉腰斜眼，配字"哈？"）]`。下一轮她知道自己刚发了什么，对方问"你这什么表情"也能接上。长期记忆整理时会忽略这类标记。
- **防出戏**：标记会在防出戏检查之前截掉，表情描述不进入检查。
- **出错**：表情下载或发送失败时，只记日志；文字照常发，不重试。

## 6. 新增配置项

| 配置 | 默认值 | 说明 |
|---|---|---|
| `STICKER_ENABLED` | `true` | 总开关 |
| `STICKER_PROB` | `0.15` | 一轮回复可以带表情的基础概率 |
| `STICKER_MIN_INTERVAL` | `180` | 同一个群（或私聊）两次表情之间最少隔几秒 |
| `STICKER_ONLY_PROB` | `0.5` | 抽中表情且本轮是"只回几个字"档时，提示只发表情的概率 |
| `STICKER_SELF_REACT_PROB` | `0.5` | 斗图时的表情概率 |
| `STICKER_RECENT_AVOID` | `5` | 最近几张不重复 |
| `STICKER_REFRESH_HOURS` | `6` | 多久重新拉一次收藏 |
| `STICKER_TIER_MULTIPLIER` | `{讨厌:0.5, 陌生人:0.7, 熟人:1.0, 很熟:1.3}` | 各档概率倍数 |
| `STICKER_PRIVATE` | `true` | 私聊也发 |

## 8. 上线前要验证的（均已验证）

1. `fetch_custom_face` 在当前 NapCat 版本的返回格式（是地址列表还是对象），以及能不能一次拿全部收藏。
2. `sub_type=1` 发出去在手机和电脑 QQ 上是不是表情样式；GIF 动图能不能正常动。
3. 打标签的准确度：先对全部收藏跑一遍，用 `/表情 列表` 人工抽查。
4. 实际频率：在测试群聊一段时间，看 15% 是否合适。

## 9. 需要你准备的

- 在小号的收藏表情里存好伊蕾娜表情包。每种情绪最好至少 2～3 张，否则只能挑到同一张，或者这种情绪干脆发不出来。
