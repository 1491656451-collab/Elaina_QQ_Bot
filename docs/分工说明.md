## 限额、休息：逻辑和说的话分开

| 说的话（聊天 agent 改） | 逻辑（限额 agent 改） |
|---|---|
| 快到休息时间犯困的提示 `WINDDOWN_SLEEP_HINT`、该睡了的收尾提示 `WRAPUP_SLEEP_HINT` | 什么时候加这两条提示 |
| 额度快用完“有点累了”的提示 `WINDDOWN_TIRED_HINT`、该收尾了 `WRAPUP_HINT` | 什么时候加、收尾几轮、几分钟 |
| 晚安台词 `peak.py` 的 `SLEEP_GROUP_LINES`、`SLEEP_PRIVATE_LINES`（`sleep_line` 怎么挑） | 什么时候发、发给谁 |
| 告别台词 `FAREWELL_GROUP_LINES`、`FAREWELL_PRIVATE_LINES`，累了的台词 `TIRED_TIERS`（`farewell_line`、`tired_line`） | 什么时候发、发给谁、发几次 |

规则：限额 agent 要加一种新的时机（比如新的告别场合），需要新台词时，先用现有台词顶上，再写进交接文档请聊天 agent 补；聊天 agent 改台词不动触发条件。
