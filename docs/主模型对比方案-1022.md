# 主模型对比方案：聊天主模型换不换 pro（10/22）

> 聊天 agent 写，任务单-1022 第三批第 1 项（聊天 agent + 限额 agent）。用户 10/22 定：先做这一项；盲评由聊天 agent 和限额 agent 各打一遍。
> **这份是方案和工具说明，结果出来后另写《主模型对比报告-日期.md》。** 只改了测试工具，机器人代码没动，不用部署。

## 1. 先确认用不用得起（摘自限额 agent《花费核算-1022》）

| | flash（现在） | pro |
|---|---|---|
| 回一次消息 | 约 0.0023 元 | 约 0.011 元（约 4.8 倍） |
| 这 7 天平均每天 | 0.073 元 | 约 0.22 元 |
| 最忙的一天（10/20） | 0.30 元 | 约 1.0 元 |
| 每天总额 1.35 元能聊几轮 | 约 350 轮 | 约 110 轮 |
| 每人份额 0.375 元能聊几轮 | 约 140 轮 | **约 33 轮** |

结论：按现在的聊天量**用得起**，但真要换，有三件事必须先做（第 5 节）。

## 2. 测什么

| 部分 | 题目 | 每个模型几次 | 调用次数 | 怎么评 |
|---|---|---|---|---|
| 回归测试 | `regression_cases.json` 全部 82 题（人设、问候、收尾、传声、日志翻车题） | 5 | 约 820 | ① 自动数翻车（出戏、抄提示、繁体字等，和平时一样）；② 每题每个模型随机挑 2 条进盲评稿 |
| 真实场景 | `phrasing_cases.json` 全部 15 题（《怪话清单-1018》里她说得别扭的地方，10/04～10/18 的真实聊天） | 5 | 约 150 | 全部进盲评稿 |

- 两个模型用**同一份**现在的人设和代码、同一个温度（1.1），只换模型；思考模式都关。
- 真实场景走机器人的真实流程（旁听、合并、拼提示、各道检查都照线上），长期记忆、识图关掉。
- 这一版里，判断“是不是在跟她说话”、讲往事后的核对也跟着用 pro（它们和回消息读的是同一个模型设置）。判断在回放里本来就是假的，只有核对有影响。
- 另外记下每次的用时，看 pro 慢多少。
- **费用**：大约四五块钱，pro 那一半占大头。pro 用 `.env` 里的 `MEMORY_PRO_API_KEY`（没填就用 `DEEPSEEK_API_KEY`）。

## 3. 怎么跑

双击 `bot\主模型对比.bat`。它先跑回归测试，再跑真实场景，大约要二三十分钟。跑完会得到：

| 文件 | 给谁看 |
|---|---|
| `docs\人设回归测试\回归_时间_盲评.md` + `_打分表.txt` | 打分的两个 agent |
| `docs\措辞对比\措辞对比_时间_盲评.md` + `_打分表.txt` | 打分的两个 agent |
| `回归_时间_答案.json`、`措辞对比_时间_答案.json` | **打完分以前谁都别看** |
| `回归_时间.md`（自动翻车统计，**标了哪个是哪个模型**） | 用户、聊天 agent（打完分以后再看） |

## 4. 怎么打分、怎么算

每条回复两个分，0～2：

- **顺**：2 = 像真人随口说的、一读就懂、接得上对方的话；1 = 能懂但有点别扭；0 = 读不通、硬凹、答非所问。
- **像**：2 = 就是伊蕾娜（自恋、嘴毒但有分寸、对熟人和陌生人分寸对）；1 = 不太像但不出格；0 = 不像她、出戏、替人说话、编了不该有的事。
- 有严重问题的（出戏、替对方说话、明显编造、该拒绝的答应了）在那一行最后写 `x` 和几个字说明。

打分表每行写成 `编号 顺 像 [x 说明]`，比如 `S01-03 2 1`、`G1-04 0 0 x 出戏`。两个 agent 各自打，**互相不看**，打完存成 `聊天agent打分.txt`、`限额agent打分.txt` 放在盲评稿旁边。

算分：

```
.venv\Scripts\python tools\blind_score.py docs\人设回归测试\回归_时间_答案.json 聊天agent打分.txt 限额agent打分.txt
.venv\Scripts\python tools\blind_score.py docs\措辞对比\措辞对比_时间_答案.json 聊天agent打分.txt 限额agent打分.txt
```

会在答案旁边写 `_计分.md`：每个模型的平均分、逐题对比、两个人打分差得多的条目、打了 x 的条目。差得多的几条由用户拍板。

**建议的判定**（用户可以改）：pro 两项合计平均比 flash 高 0.3 分以上（满分 4），x 不比 flash 多，回归测试自动翻车不比 flash 多，才值得换；差不多就留 flash。用时也写进报告，pro 慢太多也要考虑。

## 5. 如果决定换 pro，换之前要先做的

1. **记账按模型算价**（第三批第 2 项，限额 + 记忆 agent）：不改的话账面只有真实花费的五分之一左右，限额等于没有。
2. **每人份额、每轮估价跟着调**（限额 agent）：`BUDGET_USER_SHARE` 提到 0.6～0.75 元，`BUDGET_ROUND_ESTIMATE` 从 0.003 改成约 0.012。
3. **回消息单独一个模型设置**（聊天 agent）：现在判断、讲往事核对、插话 / 冒泡 / 写信 / 搭话、语音译日语、空间写说说和回评论都读 `DEEPSEEK_MODEL`（共 15 处），直接改它会全部变成 pro。要加一个“只管回消息”的设置，其余的先继续用 flash，要不要也换另说。

## 6. 给限额 agent 的话（用户转达）

> 第三批第 1 项“主模型换不换 pro”要你和聊天 agent 各打一遍盲评分。用户跑完 `主模型对比.bat` 以后，请读 `docs\人设回归测试\` 和 `docs\措辞对比\` 里最新的 `*_盲评.md`，按稿子开头的规则给每条打“顺”“像”两个分，写进同名的 `*_打分表.txt` 的一份副本，存成 `限额agent打分.txt` 放在旁边。**打完分以前不要打开 `*_答案.json` 和 `回归_时间.md`**（那两个标了哪条是哪个模型）。打完告诉用户。详见《主模型对比方案-1022.md》。
