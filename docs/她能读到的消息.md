## 2. 私聊和群里的区别

- **私聊**：卡片、名片照常回。Markdown、按钮这类消息多半是机器人发的，照旧不理。
- **群里**：
  - 群友转的卡片进**旁听记录**，只显示标题，帮她知道大家在聊什么。她不会因为一张卡片就开口。
  - Markdown、按钮照旧完全不要，免得两个机器人对着聊。
  - 旁听记录里的“回复”也会注明回的是哪句。

## 3. 群里句子中间的 @（9/30 19:45 修）

以前群里的每个 @ 都从正文里删掉，名字挪到开头当“说话对象”：

- “我觉得@小明 说得对”变成“【某某 → 小明】我觉得 说得对”：本来是跟大家说、提到小明，变成在跟小明说，正文里还少了“小明”。
- “这个问问@伊蕾娜 吧”：框架只把开头、结尾的 @ 算成叫她；判断“有没有提到她”又只看文字、不看 @，所以她多半当成群友闲聊，不回。

现在：

- **开头、结尾的 @**（中间只隔空格）才算“在跟谁说”，写在“→”后面，照旧。
- **句子中间的 @**留在原处，写成“@小明”“@伊蕾娜”“@全体成员”。
- 句子中间 @ 别人，不再当成“在跟别人说话、她别插嘴”。
- 句子中间 @ 她，算点了她的名，和文字里叫“伊蕾娜”一样，交给判断步骤看是不是在叫她。

旁听记录、判断、她回复时看到的正文都按这个来（`edge_at_positions`、`group_body`、`middle_at_me`）。私聊不受影响。

## 4. 聊天规则

“图片”那一条后面补了两句，规则还是 12 条：

- 你只看得懂文字和图片。
- 语音、视频听不到、看不到内容。
- 分享、名片、文件只看得到标题、名字，打不开里面。
- 写着“看不懂”的就是看不懂。
- 别猜里面是什么，想知道就让对方用文字说说，也别当成前面聊过的人或东西。
- “（回复你说的……）”表示对方在接那句话说。

她要是学着写了“[名片：…]”“[分享：…]”这种说明，发出去之前会去掉。

## 5. 没做的

- **语音转文字、看视频**：要接语音识别，花钱又麻烦。
- **打开转发的聊天记录**：要多调一次接口，内容可能很长，还夹着别人的私事。
- **猜拳的结果**：不同版本的 QQ 里 1、2、3 分别代表什么说法不一，没把握，先只写“看不懂”。
