  - 每条记忆带上类型、重要度（1～3）、在哪儿知道的（私聊 / 哪个群 / 空间）、哪天记的、最近哪天又聊到。

## 5. 数据格式（给要读档案的人）

`data/memory/users/QQ号.json` 新增或变化的字段：

| 字段 | 说明 |
|---|---|
| `facts` | 列表，每项 `{"id", "text", "kind", "weight", "scope", "since", "seen", "due"?}`。`scope`：`private`｜`group:群号`｜`qzone`｜`public`（迁移时判断是群里说过的、但不知道是哪个群）｜`legacy`（还没迁移） |
| `impression` | 一句话印象 |
| `told` | 她说过的：`[{"text", "date", "scope"}]`，最多 8 条 |
| `next_id` | 下一条的编号 |
| `nag_day` / `nag_today` | 今天因为纠缠扣了几分 |
| `mem_gen` | 每次 `/忘记` 加 1（正在进行的整理、迁移看到它变了，就不把旧的写回去） |
| `migrate_tries` | 迁移失败了几次（3 次就放弃，旧条目改成私聊知道的小事） |

`groups/群号.json` 的 `events`：`[{"id", "text", "date", "who": [QQ…], "weight"}]`。

读旧格式的代码不用管：`get_user` / `get_group` 读到一串句子时会自动换成条目。`ltm.fact_texts(prof)`、`ltm.event_texts(group)` 可以拿到纯文字列表。
