## 1. 版本介绍

### 1.1 这是什么

一个 QQ 角色扮演聊天机器人：用小号登录 QQ，以《魔女之旅》主角**伊蕾娜**的身份在群聊和私聊里聊天。她把小说 24 卷的经历当作自己的旅途回忆，记得每个人，对陌生人冷淡、对熟人随意，会看图、发表情、偶尔主动写信。

| 层 | 用的是什么 |
|---|---|
| 登录 QQ（协议端） | NapCat.Shell（驱动官方 QQNT 客户端） |
| 机器人框架 | NoneBot2（Python 3.10+），OneBot V11 协议，反向 WebSocket，端口 8081 |
| 大模型 | DeepSeek `deepseek-flash`（可换 `deepseek-v4-pro`；看图固定用 flash） |
| 本机模型 | WD14 Tagger（`wd-swinv2-tagger-v3`，约 470 MB），只用来认出图里是不是伊蕾娜 |
| 插件 | `roleplay_chat`（全部正式功能）、`qzone_probe`（QQ 空间接口探路，临时） |

## 2. 管理员指令

### 2.1 通用规则

- **谁是管理员**：`.env` 里 `SUPERUSERS` 列出的 QQ 号，可以写多个，例如 `SUPERUSERS=["123456"]`。
- **怎么发**：指令以 `/` 开头（`COMMAND_START`）。**私聊直接发；群里要先 @ 她**（或以她的昵称开头），例如 `@伊蕾娜 /好感 @小明`。
- **白名单不管指令**：管理员指令不受 `GROUP_WHITELIST` 限制，在不在白名单的群里 @ 她都能用。`/重置` 例外，它和聊天一样只在允许的群和私聊里生效。
- **想收到出错提醒**：管理员大号必须和机器人小号**互为好友**，否则私信发不出去，只能在控制台里看到。
- **指定对象的写法**：大部分指令后面可以跟 `@某人`、`QQ号`、`我`（或 `自己`）；`/记忆`、`/忘记` 在群里还能写 `本群`（也认 `这个群`、`群`）。
- **非管理员发了会怎样**：私聊里，或者在允许的群里 @ 她时，非管理员发的管理员指令会被当成普通聊天，由她以角色身份回复（不会执行，也不会报错）。群里不 @ 她直接发 `/xxx`，她不理。

| `/性别` | — | 查看或设置性别 | 好感度 |

### 2.3 人设与短期记忆

| 写法 | 作用 | 她的回复示例 |
|---|---|---|
| `/重载人设` | 改完 `personas\elaina.md` 后重新读取，马上生效 | `（人设已重载，19635 字）` |
| `/重置` | 清空当前群或私聊的短期记忆和旁听暂存；还没整理进长期记忆的旧消息也一起丢掉 | `（记忆已清空）` |

- `/重置` 在群里只有管理员能用，普通群友发会收到 `（只有管理员才能清空群里的记忆哦）`；私聊里每个人都能清自己的。
- 换了人设但她还在用旧口吻说话时，先 `/重置`。

### 2.4 长期记忆

| 写法 | 作用 |
|---|---|
| `/记忆 @某人`、`/记忆 QQ号`、`/记忆 我` | 查看她对这个人记住了什么：称呼、说过几次话、好感分，以及逐条的档案内容 |
| `/记忆 本群` | 查看本群往事（只能在群里用） |
| `/忘记 @某人`、`/忘记 QQ号`、`/忘记 我` | 删除这个人的长期记忆。**只删印象，不清零好感** |
| `/忘记 本群` | 清空本群往事 |

- 参数没写或写错时，会回复用法说明。
- 她记错了某人的事：先 `/记忆 @那人` 看看，再 `/忘记 @那人`。

### 2.5 好感度与性别

| 写法 | 作用 |
|---|---|
| `/好感 @某人`（或 QQ号、我） | 查看分数、档位、说过几次话、性别、上次给他写信是几天前、最近 5 次变化的理由 |
| `/好感 @某人 +10` | 加 10 分 |
| `/好感 @某人 -10` | 减 10 分 |
| `/好感 @某人 =50` | 直接设成 50 分 |
| `/性别 @某人`（或 QQ号、我） | 查看：称呼、性别、好感分、当前档位 |
| `/性别 @某人 女` / `男` | 手动设置性别（跳过她“质疑一次、对方再确认”的流程） |
| `/性别 @某人 清除`（或 `未知`） | 清掉性别 |

- 档位门槛：低于 -20 讨厌｜-20～29 陌生人｜30～69 熟人｜70 以上很熟。
- 男生和没确认性别的人，好感最高 69 分（熟人）。`CLOSE_FRIENDS` 里的 QQ 号直接算“很熟”，不受性别限制。
- 分数可以带小数，例如 `+2.5`。

### 2.6 主动写信

| 写法 | 作用 |
|---|---|
| `/写信 @某人`（或 QQ号、我） | 马上给这个人写一封，用来测试。不看好感和时间，但**对方必须是机器人的 QQ 好友** |
| `/写信 检查` | 列出所有“很熟”的人，以及每个人现在符不符合自动写信的条件；显示今天已寄几封、现在是不是寄信时段 |

- 写完会回复 `（信已寄给 xxx｜自动写信条件：符合）` 或说明平时为什么不会自动写。
- 写不成时会说原因，例如不是好友。

### 2.7 识图纠正

先**引用一张图**（或者和图一起发），再 @ 她发：

| 写法 | 作用 |
|---|---|
| `/认图` | 查看结果：本机识别出的角色、伊蕾娜置信度、门槛、结论、她看到的描述 |
| `/认图 是`（也认 `是她`、`是伊蕾娜`、`伊蕾娜`） | 以后这张图就当成她本人。同一张图重发、当表情包用都算 |
| `/认图 不是`（也认 `否`、`不是她`） | 以后不当成她 |
| `/认图 取消`（也认 `清除`、`自动`） | 恢复自动识别 |

- 没带图时会回复用法说明。
- 平时认错得多，就去调 `VISION_TAGGER_THRESHOLD`（见 4.3），`/认图` 适合纠正个别图。

### 2.8 表情包管理

| 写法 | 作用 |
|---|---|
| `/表情` | 概况：可用几张、每种情绪几张、缺哪些情绪、开关状态和概率 |
| `/表情 列表`（也认 `全部`、`list`） | 列出每张的编号、情绪、描述（✎ 表示手动改过）；每 15 条分一条消息发 |
| `/表情 3` | 把 3 号发出来看看 |
| `/表情 3 嫌弃 无语` | 把 3 号的标签改成“嫌弃、无语”；手动改过的以后刷新也不会覆盖 |
| `/表情 3 禁用`（也认 `停用`、`不用`） | 停用 3 号 |
| `/表情 3 启用`（也认 `恢复`） | 恢复 3 号 |
| `/表情 刷新`（也认 `更新`、`同步`） | 马上重新拉取小号的收藏表情；新图在后台打标签（高峰时段先不打） |
| `/表情 测试 嫌弃` | 按情绪挑一张发出来，看她实际会发哪张 |

- 可用的情绪词只有这 10 个：**得意、嫌弃、无语、生气、开心、害羞、疑惑、委屈、震惊、敷衍**。写了词表外的词会被拒绝。
- 表情库是空的时候：先在小号手机 QQ 里收藏表情，再发 `/表情 刷新`。

### 2.9 QQ 空间说说

| 写法 | 作用 |
|---|---|
| `/说说` | 显示用法 |
| `/说说 预览` | 马上生成一条（图 + 文案）发给你看，**不发布** |
| `/说说 发预览` | 把 2 小时内预览的那条发出去，今天不再定时发 |
| `/说说 立即发` | 马上生成并发出，今天不再定时发 |
| `/说说 删除最新` | 删掉她最近发的一条说说 |
| `/说说 今日` | 今天定在几点发、发了没有、日结做了没有、回了几条评论、暂停没有；列出今天的见闻（最多 12 件） |
| `/说说 图库` | 处理图库里的新图，显示图库情况 |
| `/说说 查评论` | 马上查一轮：自己说说下的评论 + 别人空间里 @ 她的，并回复 |
| `/说说 日结` | 马上把今天的聊天整理成“今日见闻” |
| `/说说 暂停` / `/说说 恢复` | 停掉或恢复自动发说说和回评论；`恢复` 同时解除风控熔断 |

- `预览`、`今日`、`图库`、`日结` 在总开关关着时也能用。
- **熔断**：空间一返回限流码（如 `-10049`）、验证页面或 403，空间功能（发说说、回评论、回 @）自动停 24 小时（`QZONE_RISK_PAUSE_HOURS`），并私信管理员。熔断期间 `发预览`、`立即发`、`删除最新`、`查评论` 会被拦下并提示原因；`/说说 今日` 会显示熔断到几点。
- **`/说说 恢复` 也会解除熔断**，提前恢复前先确认小号没有异常。
- 接口出错时会回复 `（QQ 空间接口出错：…）`，详细记录在 `data\qzone\qzone.log`。

## 4. 参数说明

### 4.1 怎么改

- 所有参数都写在 `bot\.env` 里，格式是 `参数名=值`，大小写不敏感。改完**重开 start.bat** 才生效（人设文件除外）。
- 没写进 `.env` 的参数用代码默认值（`plugins\roleplay_chat\config.py`）。下面表格里“模板里有”一栏打 ✓ 的，是 `.env.example` 里已经列出来的；空着的是只在代码里、需要时自己往 `.env` 加一行。
- 值的写法：开关写 `true` / `false`；列表写成 `["a","b"]` 或 `[123,456]`；时间段写成 `20:30-22:30`（北京时间）；字典写成 `{"close": 1.3}` 这种 JSON。
- 好感档位的英文名：`disliked` 讨厌、`stranger` 陌生人、`acquaintance` 熟人、`close` 很熟（`*_TIER_MULTIPLIER` 用到）。

### 4.4 常用调整速查

| 想要的效果 | 改什么 |
|---|---|
| 只在自己的群里说话 | `GROUP_WHITELIST=[群号1,群号2]` |
| 群里完全不说话，只用私聊 | `ENABLE_GROUP=false` |
| 只在被 @ 时说话，不主动接话 | `SMART_REPLY=false` |
| 群里插话太多 | 调大 `SMART_MIN_INTERVAL`，或关掉 `SMART_REPLY` |
| 担心风控 | 调小 `GLOBAL_RATE_PER_MINUTE`（如 6）、`GLOBAL_RATE_PER_HOUR`、`GROUP_RATE_PER_HOUR` |
| 回复太长 / 太短 | `SHORT_REPLY_MAX_TOKENS`（闲聊）、`LONG_REPLY_MAX_TOKENS`（讲故事等） |
| 打字太快 / 太慢 | `REPLY_DELAY_PER_CHAR`（越大越慢） |
| 想要一次只发一条 | `MULTI_MESSAGE=false` |
| 老扯小说 / 从不提小说 | 调高 / 调低 `KNOWLEDGE_MIN_SUMMARY_SCORE`、`KNOWLEDGE_MIN_CHUNK_SCORE` |
| 把别的银发角色认成她 | `VISION_TAGGER_THRESHOLD` 调高到 0.85 |
| 她自己的图认不出 | `VISION_TAGGER_THRESHOLD` 调低到 0.6 |
| 斗图时搭话太多 | 调大 `VISION_SELF_REACT_INTERVAL`、调低 `VISION_SELF_REACT_PROB` |
| 表情发得太少 / 太多 | `STICKER_PROB` |
| 表情发出来是大图或发不出去 | `STICKER_SUB_TYPE=-1` |
| 让某人直接“很熟” | `CLOSE_FRIENDS=[QQ号]`，或 `/好感 @某人 =70` 加 `/性别 @某人 女` |
| 聊天也涨好感 | `AFFECTION_CHAT_GAIN=1`（每天最多涨 `AFFECTION_DAILY_CAP` 分） |
| 让她更聪明（更贵） | `DEEPSEEK_MODEL=deepseek-v4-pro`（约 4 倍价格，看图不受影响） |

## 6. 整理时发现的问题

对照代码和旧文档，下面几处不一致，或者用起来要留意：

1. **`SMART_MIN_INTERVAL` 有两个值**：代码默认 60 秒，`.env.example` 写的是 15 秒，部署指南 5.1 写 15 秒、第 7 节又写 60 秒。你的 `.env` 里设的是 120 秒，实际按 120 算，不受影响；只是以后从模板重新复制 `.env` 时要记得改。
2. **`PERSONA_FILE` 的代码默认值是示例角色“小栗”**（`personas/default.md`）。`.env` 里一旦删掉这一行，她就会变成小栗。
3. **`SHORT_REPLY_MAX_TOKENS`**：代码和模板都是 80；部署指南 5.8 和第 7 节写成 90，“日常闲聊约 15～40 字”也是旧说法（现在是 10～30 字）。
4. **`.env.example` 里 `SUPERUSERS` 的注释**只写了“可用 /重载人设”，实际管理员能用第 2 节的全部指令，还会收到出错提醒。
5. **非管理员发管理员指令**会被当成聊天，由她以角色身份回复“/好感”之类的话，花一次调用。这不是 bug，只是现象上容易让人以为指令坏了。
6. **`/说说` 的指令写法不统一**：其他指令用空格分隔参数（`/表情 3 禁用`），`/说说` 要求整段完全一致（`/说说 发预览` 能用，`/说说 发 预览` 不认，会回复用法）。
7. ~~QQ 空间日记和风控保护还没并入部署指南~~：已并入（部署指南 5.14、5.15），部署指南里的限速数值也已按你 `.env` 的实际值改过。

以上只是整理文档时看到的，还没有实际在 QQ 里逐条测过。需要的话我可以挨个测一遍，结论附截图。
