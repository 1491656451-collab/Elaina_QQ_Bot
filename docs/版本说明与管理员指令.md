## 1. 版本介绍

### 1.1 这是什么

一个 QQ 角色扮演聊天机器人：用小号登录 QQ，以《魔女之旅》主角**伊蕾娜**的身份在群聊和私聊里聊天。她把小说 24 卷的经历当作自己的旅途回忆，记得每个人，对陌生人冷淡、对熟人随意，会看图、发表情、偶尔主动写信。

| 层 | 用的是什么 |
|---|---|
| 登录 QQ（协议端） | NapCat.Shell（驱动官方 QQNT 客户端） |
| 机器人框架 | NoneBot2（Python 3.10+），OneBot V11 协议，反向 WebSocket，端口 8081 |
| 大模型 | DeepSeek `deepseek-flash`（可换 `deepseek-v4-pro`；看图固定用 flash） |
| 本机模型 | WD14 Tagger（`wd-swinv2-tagger-v3`，约 470 MB），只用来认出图里是不是伊蕾娜 |
| 插件 | `roleplay_chat`（全部正式功能）、`qzone_probe`（QQ 空间接口探路，临时） |

## 2. 管理员指令

### 2.1 通用规则

- **谁是管理员**：`.env` 里 `SUPERUSERS` 列出的 QQ 号，可以写多个，例如 `SUPERUSERS=["123456"]`。
- **怎么发**：指令以 `/` 开头（`COMMAND_START`）。**私聊直接发；群里要先 @ 她**（或以她的昵称开头），例如 `@伊蕾娜 /好感 @小明`。
- **白名单不管指令**：管理员指令不受 `GROUP_WHITELIST` 限制，在不在白名单的群里 @ 她都能用。
- **想收到出错提醒**：管理员大号必须和机器人小号**互为好友**，否则私信发不出去，只能在控制台里看到。
- **指定对象的写法**：大部分指令后面可以跟 `@某人`、`QQ号`、`我`（或 `自己`）；`/记忆`、`/忘记` 在群里还能写 `本群`（也认 `这个群`、`群`）。
- **所有指令都只有管理员能用**（9/27 起，包括 `/重置`）。
- **非管理员发了会怎样**：不执行、不回复，也不当成聊天，不花 token，只在日志里记一行“不是管理员，指令不理”。群里、私聊都一样。

| `/表情` | 概况：可用几张、每种情绪几张、缺哪些情绪、开关状态和概率 |
| `/表情 列表`（也认 `全部`、`list`） | 列出每张的编号、情绪、描述（✎ 表示手动改过）；每 15 条分一条消息发 |
| `/表情 3` | 把 3 号发出来看看 |
| `/表情 3 嫌弃 无语` | 把 3 号的标签改成“嫌弃、无语”；手动改过的以后刷新也不会覆盖 |

- 表情库是空的时候：先在小号手机 QQ 里收藏表情，再发 `/表情 刷新`。

### 2.9 QQ 空间说说

| 写法 | 作用 |
|---|---|
| `/说说` | 显示用法 |
| `/说说 预览` | 马上生成一条（图 + 文案）发给你看，**不发布** |
| `/说说 发预览` | 把 2 小时内预览的那条发出去；离它不到 12 小时的定时说说会跳过 |
| `/说说 立即发` | 马上生成并发出；离它不到 12 小时的定时说说会跳过 |
| `/说说 删除最新` | 删掉她最近发的一条说说 |
| `/说说 今日` | 今天定在几点发、发了没有、日结做了没有、回了几条评论、暂停没有；熔断中、冷静期里会写几点之后才能动；列出今天的见闻（最多 12 件） |
| `/说说 图库` | 处理图库里的新图，显示图库情况 |
| `/说说 查评论` | 马上查一轮：自己说说下的评论 + 别人空间里 @ 她的，并回复；顺便刷好友动态，按几率评论 |
| `/说说 好友动态` | 只看不评：列出最近 6 小时好友发的说说、对方和她的关系、评论几率、抽没抽过签（9/28 新增） |
| `/说说 日结` | 马上把今天的聊天整理成“今日见闻” |
| `/说说 暂停` / `/说说 恢复` | 停掉或恢复自动发说说和回评论；`恢复` 同时解除风控熔断 |

- `预览`、`今日`、`图库`、`日结` 在总开关关着时也能用。
- **熔断**：空间一返回限流码（如 `-10049`）、验证页面或 403，空间功能（发说说、回评论、回 @）自动停 24 小时（`QZONE_RISK_PAUSE_HOURS`），并私信管理员。熔断期间 `发预览`、`立即发`、`删除最新`、`查评论` 会被拦下并提示原因；`/说说 今日` 会显示熔断到几点。
- **`/说说 恢复` 也会解除熔断**，提前恢复前先确认小号没有异常。
- **闸门**：机器人连上 NapCat 后 30～60 分钟（每次随机）内，`查评论` 回复“先不查：……几点之后”；`立即发`、`发预览`、`删除最新` 回复“先不发 / 先不删：……几点之后”。刚要到新凭证的 5～10 分钟内也不写。账号下线后什么都不做，重新上线后重新计时。
- 接口出错时会回复 `（QQ 空间接口出错：…）`，详细记录在 `data\qzone\qzone.log`。

## 4. 参数说明

### 4.1 怎么改

- 所有参数都写在 `bot\.env` 里，格式是 `参数名=值`，大小写不敏感。改完**重开 start.bat** 才生效（人设文件除外）。
- 没写进 `.env` 的参数用代码默认值（`plugins\roleplay_chat\config.py`）。下面表格里“模板里有”一栏打 ✓ 的，是 `.env.example` 里已经列出来的；空着的是只在代码里、需要时自己往 `.env` 加一行。
- 值的写法：开关写 `true` / `false`；列表写成 `["a","b"]` 或 `[123,456]`；时间段写成 `20:30-22:30`（北京时间）；字典写成 `{"close": 1.3}` 这种 JSON。
- 好感档位的英文名：`disliked` 讨厌、`stranger` 陌生人、`acquaintance` 熟人、`close` 很熟（`*_TIER_MULTIPLIER` 用到）。

### 4.2 框架与连接（NoneBot 自带，只在 `.env` 里）

| 参数 | 模板里的值 | 说明 |
|---|---|---|
| `DRIVER` | `~fastapi` | NoneBot 驱动，不要改 |
| `HOST` | `127.0.0.1` | 监听地址。NapCat 和机器人不在同一台机器时改成 `0.0.0.0` |
| `PORT` | `8081` | 监听端口，要和 NapCat 里反向 WebSocket 的地址一致（8080 常被 Steam 占用） |

| `NICKNAME` | `[]` | 群里以这个名字开头说话也算“叫她”，例如 `["伊蕾娜小姐"]`（必须带引号）。只想 @ 才触发就留空。**注意**：以这些词开头的消息会被直接当成 @ 她，不经过判断，而且开头的词会被删掉；只放一看就是在叫她的称呼，角色名、外号放进 `SMART_NAMES`（9/28 因此把“伊蕾娜”“屑魔女”“美少女”移出） |

| `QUEUE_MAX_WAIT` | `90` | ✓ | 每分钟限额满了时，最多排队等多久再回（秒）；等不到就不回 |

#### 4.3.18 未读消息：机器人不在线时别人发来的私聊，上线后补回

## 6. 整理时发现的问题

对照代码和旧文档，下面几处不一致，或者用起来要留意：

1. ~~**`SMART_MIN_INTERVAL` 有两个值**~~：9/27 22:56 起 `.env.example` 也改成 60 秒，和代码默认一致。原来：代码默认 60 秒，`.env.example` 写的是 15 秒，部署指南 5.1 写 15 秒、第 7 节又写 60 秒。你的 `.env` 里设的是 120 秒，实际按 120 算，不受影响；只是以后从模板重新复制 `.env` 时要记得改。
2. **`PERSONA_FILE` 的代码默认值是示例角色“小栗”**（`personas/default.md`）。`.env` 里一旦删掉这一行，她就会变成小栗。
3. **`SHORT_REPLY_MAX_TOKENS`**：代码和模板都是 80；部署指南 5.8 和第 7 节写成 90，“日常闲聊约 15～40 字”也是旧说法（现在是 10～30 字）。
4. **`.env.example` 里 `SUPERUSERS` 的注释**只写了“可用 /重载人设”，实际管理员能用第 2 节的全部指令，还会收到出错提醒。
5. ~~非管理员发管理员指令会被当成聊天~~：9/27 16:37 起不是管理员发指令她一律不理。22:56 起只认“正好是指令”或“指令后面跟空格”，“/表情真可爱”这类话不算指令。
6. **`/说说` 的指令写法不统一**：其他指令用空格分隔参数（`/表情 3 禁用`），`/说说` 要求整段完全一致（`/说说 发预览` 能用，`/说说 发 预览` 不认，会回复用法）。
7. ~~QQ 空间日记和风控保护还没并入部署指南~~：已并入（部署指南 5.14、5.15），部署指南里的限速数值也已按你 `.env` 的实际值改过。

以上只是整理文档时看到的，还没有实际在 QQ 里逐条测过。需要的话我可以挨个测一遍，结论附截图。
