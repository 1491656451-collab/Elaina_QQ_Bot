## 1. 空间这边已经做好的

`qzone_diary.space_memo(uin)`（`qzone_diary.py`，10/27 已写进电脑上的代码，还没部署）：

- 读这个人的空间聊天记录（`history\qzone_QQ号.json`），取最近 `QZONE_SPACE_MEMO_HOURS`（默认 48）小时内的，最多 4 条。
- 包括：她评论、点赞对方的说说；对方在她日记下的评论和她的回复；对方在空间里 @ 她、她的回复。
- 没有就返回空字符串。`QZONE_SPACE_MEMO_HOURS=0` 时一律返回空。
- 现在的文字（能用的版本，请润色）：

```
【你们最近在 QQ 空间里的往来】
- 昨天晚上：对方发了条说说，你刷到了，点了个赞，没留言：「今天画了一张伊蕾娜」
- 2 小时前：对方在你的日记下评论：「好看」；你回的是「谢谢，不过……」
对方提起时你知道这些事；对方没提就别主动说。
```

另外，从 10/27 起“只点了赞”也会记进空间聊天记录和待整理的长期记忆（原来只有评论会记），所以长期记忆整理后，群聊里也可能知道。

## 2. 请聊天 agent 做的

在 `reply.py` 拼提示的地方加一段，**只在私聊加**（空间的往来是两个人之间的事，群里不提）：

```python
# reply.py，long_memo / diary_memo 附近
space_memo = "" if is_group else qzone_diary.space_memo(event.user_id)
...
extra = "\n\n".join(x for x in (long_memo, life_memo, memo, time_memo, gender_memo, diary_memo, space_memo, late_memo, ...) if x)
```

- 出错不要影响回复（可以和【你的近况】一样包一层 try）。
- 文字可以按你那边的写法改，标题、措辞都行。只有一点要保留：**对方没提就别主动说**。不然她会在私聊里突然说“我刚给你点了赞”。
- 要不要也接到冷场搭话、写信里，由你定。空间这边没有要求。
