## 2. 说明

### 2.1 J08 这题要换

这轮跑的时候，题目里直接塞了一条“早上买到刚出炉的面包”给她，她 3/10 提了面包。

记忆 agent 已经按第一轮报告改了（《交接-近况接口》L 节）：对方这句和最近几句没提面包，`life_for_chat` **一条面包都不带**。所以线上她根本看不到那条，这题原来的写法已经不代表线上。

回归工具不经过记忆那边，是照题目里写的近况原样拼进提示的。所以把 J08 改成线上会给的样子：近况里只有“现在在哪”和一条不相干的（上午看了场小雨），数她提面包的次数，和改前比。

### 2.2 原话里值得留意的

- J01 改后有 2 次在猫的故事上加了点（“嫌我不给它面包”“大概嫌我无聊”），是顺口的猜测，没有和近况矛盾。
- J03 改后 1 次说“某片森林里”——近况里的地名就叫“某片森林”（题目写的），线上她说的地方会是她自己的说法，不会这样。
- J04 改后有 3 次问“上班是什么”，和改前差不多，是人设本来的样子，和近况无关。
