## 代价

- 每张图输入从约 675 token 涨到约 1011 token，多一半左右，按空闲价每张多不到 0.0004 元。
- 只有第一次看到时多花；同一张动图以后用缓存。以前看过的动图描述不会自动重写。

## 发现的另一个问题：表情的情绪偶尔读反（静图也一样）

G5、G9、G20 和聊天 agent 回放里的 K3（静图：闭眼张嘴大笑、托着下巴的得意脸，被写成“张嘴吐舌……无奈又嫌弃”）是同一类问题：**看图模型对嘴型、表情读偏，情绪跟着写反**。这和动图拼不拼没有关系，静图也会这样。见《方案-表情情绪读偏-1117.md》。
