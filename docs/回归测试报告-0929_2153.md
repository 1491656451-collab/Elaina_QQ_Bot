## 2. N08：说岔了被追问

题目：对方说“你不是很舍不得花钱吗，今天竟然这么豪爽”，她回“面包的话那是另一回事 / 少拿我跟蘑菇相提并论”（对方根本没提蘑菇），对方问“诶？蘑菇？哪有蘑菇”。

| | 改前（10 次） | 改后（10 次） |
|---|---|---|
| 认了 | 0 | 9 |
| 说是打比方、随口举例 | 1 | 1 |
| 只是岔开 | 4 | 0 |
| 赖到对方头上 | 5 | 0 |

一条条看原话数的。脚本原来的判定只抓到改前 2 次赖账，漏了“你的耳朵没问题吗？”“是你听岔了吧”“谁让你把我跟那个相提并论了”这几种，已经补进判定里（重判后改前 5 次、改后 0 次）。

改后的原话：

- ……说岔了，当我没说。（3 次，有的后面还接了一句）
- 说岔了，当我没说
- 啊，说岔了，当我没说
- 刚才是我说岔了，当我没提
- 啊，不对，扯远了 / 我的意思是：面包值得花钱，就这样
- 我在说蘑菇有多讨人厌，别让我在面包店里想起它 / ……说岔了，当我没说。
- 我自己说的，不行吗 /（……好像扯远了）
- 我随口举个例子而已，别在意

新的问题是**说法太整齐**：10 次里 7 次是“说岔了，当我没说 / 当我没提”。这是人设和规则里给的例句，她照着说了。意思对，但真人不会每次都这么说，交给人设那边换成几种说法（见第 5 节）。

## 3. N11：讲往事被反问

新加的题，检查她正常讲往事时被问“梦回之城？那是哪”，会不会也被“这个词是你先说起的”提示带偏，把说对的话收回去。改后 5 次：

| 回复 | 看法 |
|---|---|
| 就是一个叫卡尔赛尔的国家，你没听过也正常。 | 好 |
| 就是那座一直重复同一天的城市啊。 | 好 |
| 就是卡尔赛尔啊 / 那座城一直卡在同一天里出不来…… | 好 |
| **啊，是我自己起的叫法。那座城叫卡尔赛尔。** | 把“梦回之城”这个真名说成自己起的，**被提示带偏了** |
| 全城的人到了晚上都会做同一个梦…… | 把“重复同一天”和“做梦”混了，**是题目的锅**（见下） |

要改的两处，都已改：

- **题目写错了。** 我给这题写的前一句是“整座城的人每天晚上都会做同一个梦”，可人设里写明梦回之城“是整座城一直重复同一天，不是做梦”。她是顺着我写错的前一句说的。已改成“整座城一直在重复同一天，城里的人谁都没发觉”。
- **提示的说法。** 原来写“「梦回之城」是你自己先说的”，她理解成这个名字是她自己起的。改成“对方前面没提过它，是你先说起的”，还加了一句“如果是你真去过的地方、真遇到过的事、真想说的话，就照实解释，别收回”。

改前没有这句提示，5 次都照实解释了，没有收回的。

## 5. 交给人设那边的

1. **“说岔了，当我没说”太整齐**：N08 改后 10 次里 7 次是这句（或“当我没提”）。人设“有主见”和示例里都给了这句例句，可以换成只写态度（嘴硬地认、别开眼、转回正题），或者多给几种说法。
2. **面包**：规则里的“喜好别硬扯”加回去了。下一站、近况、问候还是容易拿面包填，可以在人设里给这几种场合补点别的内容（比如近况：在某国看了什么、遇到了什么人）。
