# 交接：聊天截图里认出她自己（聊天 agent → 识图 agent）

> 2026-11-06，聊天 agent 写。用户定的：她看到别人发来的、有她参与的聊天截图时，认不出哪些话是她说的。
> 要改的是 `vision.py` 的看图提示，是你的文件，我没有动。改法下面只是建议，你定。

## 现象

用户发现：发给她一张“她和别人聊天”的截图，描述里写的是“聊天截图，A 说……，B 说……”，她不知道其中一方就是自己，会当成别人的对话来评论。

转发的聊天记录（合并转发）这边今天已经解决了：她自己说的标成“你自己：……”（昵称是她的、而且她确实说过这句才算），见《问题排查记录-转发和怪话-1106.md》第 6～10 节。截图走的是识图，只能靠看图模型认。

## 截图里能用来认她的线索

| 情况 | 线索 |
|---|---|
| 群聊截图 | 每条消息上面有发送人的群名片 / 昵称。她的 QQ 昵称是 **灰之魔女_伊蕾娜**，群名片可能不一样 |
| 私聊截图（对方截的） | 不显示每条的名字；顶部标题是聊天对象的名字（对方给她的备注或她的昵称），**左边**的气泡是她说的 |
| 私聊截图（她这边视角） | 不会有，她不截图 |
| 头像 | 她的 QQ 头像（问用户是哪张图；或者用户把图放进 `tools\识图对照图\`） |

注意：不能只看左右。截图是谁截的不知道：对方截的，她在左边；如果是别人和她的群聊截图，左右要看截图的人是谁。

## 建议的改法（你定）

1. `DESCRIBE_PROMPT` 里聊天截图那句补上：昵称或顶部标题是“灰之魔女_伊蕾娜”（或者写着伊蕾娜）的那一方是她本人，描述里写成“伊蕾娜（你）说……”；认不出就照常写。
2. 头像：如果用户能给她的头像，可以在提示里描述一下头像的样子（比如“头像是……的那一方”），不用真的比对图片。
3. 聊天规则里“其他图里的人哪怕也是灰发少女，也不是你”这句可能和第 1 条打架。你定了描述的写法以后告诉我，我在聊天规则里补一句“截图里写着‘伊蕾娜（你）’的是你自己说的话”。

## 怎么测

- 用之前的复杂图测试（`识图复杂图测试.bat`），加几张截图：
  - 群聊截图，她（灰之魔女_伊蕾娜）和别人各说了几句；
  - 私聊截图，顶部标题是她的昵称；
  - 一张和她无关的聊天截图（不该写成“你”）。
- 截图可以请用户从 QQ 里截。
