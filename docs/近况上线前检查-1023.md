## 3. 小问题

### 3.1 "还没说过"没写进提示（和方案不一样）

方案里说没有"现在在哪"时，给她一句"你还没说过自己现在在哪，被问起随口说一个"。现在是什么都不写。

影响不大：没有记录时，她被问起照样会随口说一个地方，只要说得像"在某个镇""在森林里赶路"，就会被记下来。补这一句主要是让开头那段空白更快填上。**可以先不补**，上线后看 `/近况` 里"现在在哪"多久能有。如果一直空着，再请聊天 agent 补。

### 3.2 "现在在哪"认得比较严

只有她明说"到了……""在……落脚"这类才记。好处是不会把往事、玩笑记成现在；坏处是她说得随意时会漏（比如"这边的集市"）。回放里真实聊天说到地方的只有 1 段，还看不出漏得多不多。上线一两周后用 `/近况` 看看，漏得多再按方案说的"出现地点词就马上认一次"。

### 3.3 一处过时的注释

`core.py` 第 106 行注释还写着"生成事件归聊天（life_events.py）"，随机事件已经撤了。不影响运行，记忆 agent 下次改 `core.py` 时顺手删掉就行。

### 3.4 你测试时要知道的

手动 `/冒泡`、`/写信`、`/搭话` 是真发出去的，**也会记进近况**（这是对的，群友确实看到了）。测完不想留的，用 `/近况` 看序号、`/近况 删 N` 删掉。
