# 调研：记忆检索要不要换成 RAG / 重排（11/14）

> 2026-11-14 写。用户看到"RAG 对记忆效果最好""向量检索 + 重排""Qwen3.7"的说法，问要不要用。这份只做评估，没改东西。**用户 11/14 定：暂时不用**。以后要做，按第 5 节写交接给记忆 agent。

## 1. 现在的长期记忆怎么取

- **先整理**：夜里把聊天整理成一条条事实，带类型、重要度、在哪知道的，再附 2～4 个近义词（`memory.py` 整理提示，"关键词 tags"）。
- **每轮再挑**（`memory.py` 的 `context_for`）：拿对方这句话和最近几句，跟每条记忆的正文和近义词比两字组合，挑出相关的；再加上最重要的几条。按关系带 8～30 条，私聊知道的事在群里不带。
- **本质上已经是 RAG**，只是用字面匹配，没用向量。小说知识库也是检索式的。

## 2. 和"向量检索原始聊天"比

| | 现在（整理 + 字面挑选） | 向量检索原始聊天 |
|---|---|---|
| 换个说法也能想起来 | 靠近义词，偶尔漏 | 更强 |
| 前后矛盾 | 整理时改旧的那条 | 新旧都可能被捞出来 |
| 私聊不进群 | 每条标了来源 | 要另外过滤 |
| 转发里第三个人的话 | 整理规则挡 | 原样存进去 |
| 服务器 | 不用加东西 | 要加模型或接口 |

**结论**：整理那一步不该换。这个项目踩过的坑（性别误判、记错人、转发混进来）都是原始聊天容易出的错，整理就是在挡这些。

## 3. "记了但想不起来"是什么

模型本身不记东西，每轮只看到程序挑出来的几条。"想不起来"有五种原因，只有第一种和第二种能靠换检索改善：

1. **说法对不上**：档案记着"养了只橘猫"（近义词：猫、宠物、喵），对方说"我家主子又把纸巾扯出来了"，一个字都对不上，没被挑中。
2. **名额不够**：陌生人每轮只带 1 条重要的 + 2 条相关的。
3. **故意不给**：私聊的事不进群，这是设计。
4. **送到了没用上**：模型没注意，带得越多越容易出现。
5. **根本没记**：整理漏了，不是"想不起来"。

排查时先看档案里有没有，再看那一轮提示里带了没有。

## 4. 可选的升级：只加重排

- **向量检索 + 重排**是常见搭法：向量从海量资料里粗筛，重排模型对"问题 + 一条资料"精确打分。
- **这个项目不需要粗筛**：一个人最多 30 条记忆，可以直接把这句话和全部记忆交给重排模型打分，取最高的几条。
- **只能走接口**：最小的本地重排模型也要 1 GB 以上内存，2 GB 的服务器放不下。
- **候选**：千问 AI 平台的 `qwen3.7-text-rerank`。
  - 文本输入 0.5 元 / 百万 token，RPM 3000，输入上限 32768 token。
  - 官方说比上一代 qwen3-rerank 更强，特别提到"记忆检索"，这是厂商自己的说法。
  - 估算：一轮约 700 token，约 0.0004 元，一天不到 1 分钱。
  - 没查清的：接口地址和请求格式（模型页没写，要看接入文档）、免费额度、发布时间。
- 同平台还有 `qwen3.7-text-embedding`（0.5 元）、`qwen3.7-text-embedding-flash`（0.125 元），这个项目用不上。
- 开源的 Qwen3-Embedding / Qwen3-Reranker（2025 年 6 月）在硅基流动等平台也有接口，可以作为备选。

## 5. 以后要做时

**什么时候做**：出现"档案里有、那一轮没带、对方说法和记忆对不上"的实际例子（第 3 节第 1 种），而且不止一两次。

**交接给记忆 agent 时写清楚**：

1. **先对比，后接入**：
   - 从服务器快照取几个记忆多的人，挑十几句他们说过的话；
   - 故意加几句说法对不上的；
   - 比较现在的字面匹配和重排各挑出哪几条，写报告给用户定。
2. **只改挑选那一步**（`context_for` 里挑相关记忆的部分），整理、存档、来源过滤、条数上限都不动。可以是"字面 + 重排"合并打分，也可以只在字面挑不满时用重排补。
3. **出错要能退回**：接口超时（建议 1～2 秒）或报错，退回现在的字面匹配，不能卡住回复。
4. **记账**：重排的花费记进 `budget.py`，单独一类。
5. **Key 放 `.env`**，开关默认关，上线前回放。
