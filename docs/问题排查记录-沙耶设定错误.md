# 问题排查记录：伊蕾娜把沙耶说成“爱吃蘑菇的辫子女仆”

日期：2026-09-25

## 1. 现象

群聊中，伊蕾娜先后说了几句关于沙耶的话：

- “以前逼着沙耶吃蘑菇的那个晚上”：基本正确。
- “东边来的那个爱吃蘑菇的少女”：错误。
- “东边来的辫子女仆，叫沙耶”：错误。

## 2. 原文核实

| 说法 | 结论 | 原文依据 |
|---|---|---|
| 沙耶爱吃蘑菇 | ❌ 错。她**最讨厌蘑菇**，原话是“人家最讨厌蘑菇了” | 第4卷第三章《挑食》 |
| 伊蕾娜逼沙耶吃蘑菇 | ✅ 对。伊蕾娜以“挑食当不上魔女”为由，把自己盘里的蘑菇全夹给沙耶。其实伊蕾娜自己也最讨厌蘑菇 | 同上 |
| 沙耶是辫子 | ❌ 错。沙耶是**整齐的黑色短发**，长度齐肩 | 第1卷第一章、第8卷第四章、第16卷第四章 |
| 沙耶是女仆 | ❌ 错。沙耶是炭之魔女、魔法统合协会职员。初遇时她在旅馆打工，但不是女仆 | 第1卷第一章、第2卷第八章 |
| 沙耶是东方出身 | ✅ 对 | 第1卷第一章、第18卷第三章 |

几处错误可能的混淆来源：

- 后脑绑两个辫子的是**尤莉**（第4卷第二章）。
- 第1卷第六章的女仆**妮诺**是东洋黑长发，伊蕾娜说她和沙耶“有几分相似”。
- 伊蕾娜和**艾维莉亚**在第8卷的猫耳女仆咖啡厅打过工。

## 3. 原因

1. **人设里没写配角的外貌和喜好**：旧版人设只写了伊蕾娜和各人的关系，没写沙耶的外貌，也没写她讨厌蘑菇。模型只能靠自己脑补。
2. **只有提到名字才会检索回忆**：第二句“最喜欢哪一位？”没有点名，所以没有带上任何回忆。第三句沙耶的名字是模型自己说出来的，检索没能事先把资料送进去。
3. **追问时没带上伊蕾娜自己上一句话**：追问“这是哪一位”时，检索只参考了用户的上一句，没参考伊蕾娜自己的上一句回复。

## 4. 修复

1. **新增角色档案** `knowledge\characters.md`：
   - 内容：伊蕾娜本人加 41 位角色，写明外貌、自称、喜好厌恶、与伊蕾娜的关键事件、现况、常见误解。
   - 核对：每一条都在原文里查过并注明卷章，查不到的写“原文未写明”。
2. **点名即带档案**：群友的话里（或者追问时的上文里）出现某个角色名，就把这个人的档案作为“角色资料”发给模型，并规定外貌、喜好一律以档案为准。
3. **追问检索带上双方上一句**：遇到“哪位”“是谁”“她”“后来”这类追问，会把用户上一句和伊蕾娜上一句一起拿去检索。
4. **人设补充主要角色速查**：
   - 在人设里写入沙耶、芙兰、席拉、美奈、艾姆妮西亚、艾维莉亚、扫帚的外貌和关键喜好。其中沙耶“和你一样最讨厌蘑菇”加粗强调。
   - 新增一条规则：说到任何人的外貌、喜好，只说写明的内容，不许随口补“辫子”“女仆”之类的设定。
5. **顺带修正核对时发现的 5 处摘要错误**：
   - 第11卷：把席拉误写成“伊蕾娜的师父”（应为沙耶的师父）。
   - 第21卷：亚卡娜的发色写错（应为灰色短发、樱花色眼睛）。
   - 第21卷第六章：自称“薇多利加”的魔女身份，原文没有明说，不能断定是伊蕾娜。
   - 第5卷：送席拉烟管的人，原文只说是“一个徒弟”，没点名是沙耶。
   - 第9卷：爱露堤和莉娜莉亚首次登场是第7卷。
