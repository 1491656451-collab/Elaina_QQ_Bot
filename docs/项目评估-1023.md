## 2. 这两天最重要的发现：真实用量很小

这一条决定了接下来该把精力放在哪。

| 数据 | 来源 |
|---|---|
| 10/15～10/21 七天，回消息一共 **123 次**，平均每天 18 次；最多的一天 74 次（有测试） | 《花费核算-1022》 |
| 七天花了 **0.511 元**，平均每天 0.073 元，是 1.5 元上限的 5% | 同上 |
| 线上 42 个人里，**39 个陌生人**、2 个讨厌、1 个熟人；普通朋友、很熟 0 人 | 《好感档位检查-1022》 |
| 空间 22 天回了 21 条评论，好友说说 0 条，别人空间的 @ 0 处 | 《空间抽查-1022》 |
| 识图"再确认"两周触发 0 次；冷场搭话、写信两周各 1 次 | 识图、好感报告 |
| 发前清理 21 道，两周里真正触发的只有少数几道 | 《发前清理清单》 |

这说明：

1. **机制已经远多于实际会遇到的情况。** 很多功能（档位、写信、搭话、好友评论、再确认）线上几乎没跑过，好不好用其实还不知道。
2. **调优主要靠合成测试**（回归、措辞对比、传声测试），每题 5～20 次。线上真实对话每天十几轮，能拿来验证的不多。
3. **钱不是限制。** 按现在的量，预算和预留都很宽裕，省钱方向的优化可以不再做。

每一轮的依据是 20 次左右的测试，最后基本回到了出发点。单看每一步都有道理，但这种小样本下的来回调整，容易被波动牵着走，也让版本说明越来越长。

建议：以后改一处提示前，先写下"改成什么样才算好"（比如"陌生人要语音答应不超过 3/10"）和要问几次；没到标准就整体退回，不在同一晚上连续微调。
