## 1. 主动说话从已有经历挑：不做

- DS 说的位置不太准：BUBBLE_PROMPT 里没有"也可以写新的"。这句在 `LIFE_PROACTIVE_HEAD`（冒泡、写信、搭话共用）和 LETTER_PROMPT 里。
- 更重要的是方向。11/05《人机感检查-周到型》F 条的问题就是她**反复讲同一件事**："海"两周 33 次，"帽子被吹跑"三天讲了 3 次。为此记忆 agent 加了 `told_here` / `told_elsewhere`，提示里写明"这次说点别的，别换个说法再讲同一件事""别讲同一类事，换个完全不同的话题"。
- 改成"优先从最近说过的里挑"，等于让她回去复述旧事，会和这两句打架，把 11/05 修好的问题带回来。
- 编新的小事本身不是问题：真人每天本来就有新的小事，而且编出来的会被 `self_memory` 记下，之后被问起照着说，不会前后矛盾。
- 如果 DS 担心的是"说过要动身却一直原地不动"这类接不上的情况，11/05 的打算提示（`LIFE_PLAN_TEXT`）已经在管了。
- "fresh 命中比例低"不能说明有问题：命中低，恰恰说明她没在重复。

## 2. "可以不认真回"的中间态：做

- 现在的 skip_memo 只给两条路：完全不回（`[不回]`），或者正常回。中间的"嗯""行""哈"没有提示过。日志里一个月一次都没有只回几个字的轮（见《聊天真实感现状-1109》2.1）。
- DS 说的触发条件就是现在 skip_memo 的条件：12 字以内、不是问句、她上一句没在问、没送东西。条件严，不太会出现该认真回却敷衍的情况。合进同一段、不加程序也对。
- **要注意两点**：
  1. 提示里别写具体的字。写了"嗯"，她就会每次都回"嗯。"（这个项目一直如此）。只写"可以只回一两个字或一个表情"。
  2. 现在"只发表情"要等到这轮是"只回几个字"时才会触发（`reply.py` 第 667 行看的是 `length_hint`），skip_memo 生效时不会触发。可以顺手让 skip_memo 生效、又抽中表情时，也允许只发表情。
- **验证**：用《人机感回放》的老题跑一轮，数一下"只回 1～4 个字""[不回]""正常回"各占多少，再看熟人和陌生人有没有区别。上线一周后，从日志里数整轮 ≤4 字的比例。
- 这条只覆盖 12 字以内的水话。对方开玩笑、感叹这类更长的话，她还是会认真回一句。先看这条的效果，再决定要不要放宽。

## 3. 空间往来别"报告式"：可以顺手做

- 现在的 `SPACE_MEMO_TAIL`："对方提起时你知道这些事；对方没提就别主动说。"
- DS 想加"提的时候像随口带一句，别复述列表"，方向没问题。但"像随口带一句"容易被读成"可以带一句"，反而让她主动提起，也就是 10/27 交接时担心的"我刚给你点了赞"。
- 建议把条件写在前面，比如："对方提起时你记得这些，像记得那样接一句就行，别把这些一条条复述出来；对方没提就别主动说。"
- 目前没看到"报告式"的实例。可以先请聊天 agent 从日志里找一两次她接空间话题的回复，确认确实有这个问题再改。

## 4. 搭话时想起【可以问问】：已经有了

- 搭话（`proactive_private.py` 第 225 行）带的提示里有 `FAMILIARITY_HINT[fam]`。熟人、很熟两档本来就写着"长期记忆里有【可以问问】时，找个自然的时机顺口问一句……别像查岗"。写信也有同样的一句。
- 【可以问问】只给熟人、很熟。按《好感档位检查-1022》，线上只有 1 个熟人，搭话两周也只有一两次。再加一句，几乎碰不到效果。
- 不用做。

## 建议的顺序

1. 只做第 2 条，交给聊天 agent，先回放再部署。
2. 第 3 条先查日志，确实有报告式再改。
3. 第 1、4 条不做。
