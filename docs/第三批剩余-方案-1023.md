## 2. 顺序

一批做完、程序测试过了，再做下一批，每批记一行版本说明。

1. **第一批：A2、A4、A1、C1**。都是小改动，改的地方各自独立。
   - A2、A4 会改她说话，改完跑回归里相关的题：出戏 S14、外文 S16，加问候几题看 A1。
2. **第二批：C2 + A3**。先把 `_converse` 拆成“拼提示 → 调模型 → 检查和重说 → 发送”四步，只挪不改，跑程序测试；再在“检查和重说”这一步里做 A3（重说后整套再查一遍）。
3. **第三批：C3**。四个主动说话流程合用一套，只挪不改。
4. **第四批：B1、B2**。在 C3 合好的流程上做 B1 最省事；B2 先做公用函数，再换上聊天自己的 /插话、/冒泡。
5. **第五批：B3 测试模式**。聊天这边先做开关、主流程不交给记忆，再交给记忆、好感 agent 接上。
6. **B4、C4** 交给对应 agent，什么时候做由它们排。
