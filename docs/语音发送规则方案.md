# 伊蕾娜发语音：发送规则（已定，10/20）

> 2026-10-20（聊天 agent）。按你 10/20 的决定改写，取代初版方案（初版里的建议，你改了的地方以这里为准）。代码已经写好，还没部署。声音怎么来的见《样音对比报告-第6轮.md》。

## 前提

- **你电脑上的 `voice_service\启动语音服务.bat` 开着、隧道连着**，她才会发语音。连不上时一切照旧，只发文字，别人察觉不到。
- 机器人每分钟在后台问一次电脑上的服务还在不在，不会让聊天等。

## 什么时候发

| 情况 | 规则 | 参数 |
|---|---|---|
| 抽签 | 每次回复抽一次：**私聊 20%、群聊 15%**，再乘关系倍数（讨厌 0、陌生人 0.3、普通朋友 0.7、熟人 1、很熟 1.5）。抽中了，这条回复就用语音发 | `VOICE_PROB_PRIVATE`、`VOICE_PROB_GROUP`、`VOICE_TIER_MULTIPLIER` |
| 对方要她发语音 | **10/20 起由她自己判断对方是不是在要**：电脑上的语音服务连着时，每轮都告诉她“对方想听你的声音时可以用传声魔法”，“再来一条”“想听听你的嗓音”这种不带关键词的说法也认得出（`VOICE_REQUEST_BY_MODEL`，关掉就回到认关键词：对方说"发个语音""想听你的声音""说句话给我听"之类才告诉她）。陌生人、普通朋友后面补一句倾向：“多半婉拒” / “看心情”（熟人、很熟试过补“偶尔不给”，没用，撤了）。**她自己愿意**才用语音（回复开头写「[传声]」），不愿意就用文字回，可以拒绝、吐槽。**不限次数**，全看她自己。讨厌的人不给这个选择 | — |
| 只回一个语气词 | 她整句只有"哈？""嗯。""欸？"这类时，30% 用原声 | `VOICE_INTERJECTION_PROB` |
| **上限** | **所有人加起来每天最多 30 条**（从凌晨 5 点算一天；机器人重启会清零）。这是唯一的限制 | `VOICE_DAILY_MAX` |

10/20 取消的限制：同一个会话的间隔、字数（只剩电脑上服务 120 字的技术上限）、每人每天要几次、收尾和快睡觉时不发、群里减半（改成群聊 15%）。高峰期整个功能也关了（另一项改动）。

## 怎么发

| 项 | 做法 |
|---|---|
| 语音和文字 | 语音**代替**文字，不再发一遍同样的话；这一轮要是还抽中了表情，语音之后再甩表情 |
| 念之前清理 | 去掉颜文字、括号、波浪号，换行改成逗号；**有英文字母的不念**，改发文字 |
| 等待时间 | 按"录一段语音"算：语音长度加 1～2 秒，合成用掉的时间扣掉 |
| 引用 | 语音消息带不了引用，群里也不引用 |
| 失败 | 合成 8 秒没回来，或者发送失败，马上改发文字，不报错、不重试 |
| 聊天记录 | 写成"[发了语音] 原话"，她知道自己用语音说过这句话；规则里告诉了她这是她的传声魔法 |
| 长期记忆 | 只记原话，和文字一样 |

## 管理员指令

| 指令 | 作用 |
|---|---|
| `/语音 说 文字` | 用她的声音念一句给你听（单个语气词用原声） |
| `/语音 状态` | 电脑上的服务连没连上、用的哪个模型、今天发了几条 |
| `/语音 测试`、`/语音 文件名`、`/语音 列表` | 第 0 步留下的测试指令 |

想临时关掉自动发语音，把 `.env` 里 `VOICE_ENABLED` 改成 `false`，`/语音 说` 照样能用。

## 还没做的

- **人设里加"传声魔法"**：现在只在聊天规则里有一句"「[发了语音]」是你用传声魔法传过去的话"。人设里最好加一小段，比如"偶尔用传声魔法把自己的声音传过去，费魔力，不常用"，这样对方问"你怎么发语音了"，她答得更自然。这部分归人设 agent（claude-b3），需要你转达。
- **`/语音 开`、`/语音 关`**：不重启就能开关。要的话再加。
