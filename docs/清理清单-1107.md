## 5. 脚本怎么用

双击 `D:\QQBot\清理-1107.bat`：

1. 先把 3 档要处理的东西连同大小全部列出来，这一步什么都不动。
2. 问你处理到第几档，输入 1、2 或 3（档是累加的），直接回车就是取消。
3. **不会真删**：东西会挪进 `D:\QQBot\_待删除_1107\`，保持原来的目录结构，并记一份清单。这个文件夹自带 `.gitignore`，git 看不到它。
4. 挪完跑一次 `bot\程序测试.bat`。正常的话，你手动把 `_待删除_1107` 整个删掉，这时才真正腾出空间。
5. 挪错了可以在命令行运行 `清理-1107.bat 还原`，会按清单全部放回原处。

注意：第 3 档会动 git 里的 bat，之后 `git status` 会显示这些文件被删除，提交一次就行。

自测情况：

- 在一份假的目录上，把“列出 → 挪走 → 还原 → 再挪走”整个流程跑过一遍。要留的东西（完整模型、7 个快照、识图测试和对话回放测试的 bat、0930a、人设备份）都没被动。
- 又在你的真实文件夹上只跑了“列出”这一步，什么都没动：一共 112 项、49.2 MB（第 1 档 37.5 MB、第 2 档 7.5 MB、第 3 档 4.3 MB）。保护名单也测过：故意让它处理 `server_logs`、`10-18_1621`、`bot\data`、人设备份，都被拦下来了。
