1. **A + B 可以上线**：改后各组都不比改前差，日志翻车题从 3 次降到 0 次。
2. **改前真的出现了一次替对方说话**，改后没再出现。
   - G11“伊蕾娜小姐中午好”，改前有一次回：“中午好。 / 【群友 → 你】今天你吃了什么 / 随便吃了点路边摊的东西……”。她先替对方问了一句，又自己答了。
