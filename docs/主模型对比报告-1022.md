# 主模型对比报告（10/22）：聊天主模型先不换 pro

> 聊天 agent 写，任务单-1022 第三批第 1 项。方案见《主模型对比方案-1022.md》。
> - 原始结果：`docs\人设回归测试\回归_1022_2018*`、`docs\措辞对比\措辞对比_1022_2021*`（用户 10/22 晚上跑的 `主模型对比.bat`）。
> - 打分：聊天 agent、限额 agent 各打一遍盲评，**都是打完分才看答案**。计分结果在两个文件夹里的 `*_计分.md`。
> - 两边用同一份现在的人设和代码、同一个温度 1.1，只换模型，思考模式都关。

## 1. 结论

**建议先不换，继续用 flash。** pro 每次回消息贵约 4.8 倍、慢约一半，可这次盲评分数没有更高，反而略低。最明显的是三个毛病：

1. **不听“该收尾 / 该睡了”的提示**：收尾那组 6 道题，flash 5 次里有 3～5 次照着提示收尾，pro 是 0 次（第 3 节）。线上额度快用完、快到睡觉时间时，她就不会顺势道别。
2. **更爱编小说里的事**：编了月考被芙兰罚、妈妈“现在是普通妇女”、艾姆妮西亚的经历、星尘魔女说过的话、在梦回之城遇见安妮洛特等。两个人都标了 x 的严重问题，pro 5 条，flash 2 条。
3. **对陌生人也答应发语音**：陌生人要语音，flash 5 次都婉拒，pro 答应了 4 次（人设里写的是陌生人多半婉拒）。

按方案里的标准（两项合计高 0.3 分以上、x 不多、自动翻车不多才换），这次一条都不满足。

## 2. 盲评分数（每条“顺”“像”各 0～2 分，合计满分 4）

|---|---|---|---|---|---|
| 回归测试 82 题（每题每模型随机挑 2 条） | 164 | **3.71** | 3.51 | −0.20 | flash 5、pro 8 |

- **差得多的只有 5 条**（两人有一人标了 x 或差 2 分），都不影响结论，见各自的 `_计分.md`。

## 5. 怎么理解

- 这些提示（收尾、休息、关系分寸、传声）是这几周对着 flash 一点点调出来的。pro 不听收尾提示，不一定说明它本身差，也可能是这套写法正好合 flash 的脾气。真想用 pro，得把这几段提示再对着 pro 调一轮。照现在的价钱和效果，不值得。
- **这次没测的**：长期记忆、识图都关着；判断“是不是在跟她说话”在回放里是假的；pro 开思考模式没测（更慢、更贵，温度也会失效，聊天不适合）。
