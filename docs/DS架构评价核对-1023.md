# DS 架构评价核对（10/23）

> 2026-10-23 写。对照电脑上 10/23 02:58 部署的代码（`prompts.py`、`proactive_*.py`、`reply.py`、`voice_chat.py` 等）和项目里的报告，逐条核对 DeepSeek 对现在架构的五条评价。
> 只读，没改代码。代码没有逐行全看，下面写明了每条结论看的是哪里。

## 0. 总体

DS 的评价是读代码结构得出的，**方向（主动、情绪、连贯、语音的感情）是对的，都是"陪伴感"的问题**；但它不知道两件事：

1. **不少地方已经做了**：第一、四条说的情况，代码里已经处理了。
2. **线上用量很小**：一周回消息 123 次（平均每天 18 次），主动说话两周只有个位数。它担心的"乱主动""一天聊几十个人到晚上不累"，线上基本碰不到。

| # | DS 说的 | 核对结论 | 建议 |
|---|---|---|---|
| 一 | 主动说话只看抽签，不看内容 | **不成立**，四种里三种已经是"她自己决定" | 不改；写信可以补一个"不写" |
| 二 | 情绪是平的 | **部分成立** | 有道理，但新加一层状态风险不小，观察期后再说 |
| 三 | 主动说的事不进记忆 | **部分成立**：进短期记忆，不进长期记忆 | 值得做，范围收窄到冒泡和写信，观察期后做 |
| 四 | 群里单线，B 的话被忽略 | **基本不成立**：叫她的话会排队回，不会丢 | 不改 |
| 五 | 语音没有情绪和关系 | **成立**，但现在就有办法往前走一步 | 低优先，可以按情绪挑参考音频 |

## 1. 第一条：主动说话"抽中之前先问想不想说"

**DS 的说法**：插话、冒泡、搭话、写信都是"抽签 + 时间窗 + 次数上限"，没有一个看"现在值不值得说"。

**核对**（`prompts.py` 第 212～241 行、`proactive_common.py`）：

| 主动行为 | 抽中以后 | 她看得到什么 |
|---|---|---|
| 插话 | 提示写"真的有想说的才插……不感兴趣、插不上话、插了会突兀，就只输出「[不插]」" | 最近的群聊旁听 |
| 冒泡 | "不想说就只输出「[不说]」"；还写明上面的聊天早就过去了、别接 | 群里之前的聊天、现在几点 |
| 冷场搭话 | "要不要主动再说一句，由你自己决定……不想说、没什么好说的，就只输出「[不说]」，这很正常"；对方道别了、搭话突兀也不说 | 你们的私聊、关系 |
| 写信 | **没有**"不写"的选项，抽中就一定写 | 长期记忆、最近聊天 |

`proactive_common.py` 统一处理：写了「[不插]」「[不说]」、空的、出戏的，都不发。日志里也看得到"她看了看，没什么想说的""她不想说话"。

所以"没有一个看内容"不对：插话、冒泡、搭话都是**抽签决定"看一眼"，看了之后由她决定说不说**。

**DS 提的改法**是"抽中之前先问"，也就是先问想不想说、想说才进抽签。这和现在的"先抽签、抽中再问"，在"她自己决定"这一点上效果一样，区别只在：

- 先问的话，每个可能的时机都要调一次模型（插话是群里每来一条热聊消息、冒泡是每 20 分钟检查一次），调用次数多很多；
- 而且问完还要再抽签，等于她想说的时候也可能被签挡掉，反而更不像"想说才说"。

**线上情况**：两周里冒泡、搭话、写信各只有一两次（《好感档位检查》2.3）。现在的问题是主动得少，不是乱主动。

**建议**：不改。唯一可以补的是**写信也给一个"不想写就不写"的选项**（和另外三种一致），归聊天 agent，改动很小，不急。

## 2. 第二条：情绪是平的

**DS 的三个例子逐个看**：

| DS 说的 | 实际 |
|---|---|
| 被踩雷扣了分，下一轮语气不变 | **部分对**。扣分本身确实不会给她加一句提示（`reply.py` 第 695 行只扣分）。但那句冒犯的话就在聊天记录里，她下一轮看得到，人设里也写了被冒犯会冷下来，所以同一段对话里语气多半会变。只是没有程序上的保证 |
| 被讨厌的人烦完，紧接着回熟人，不带余味 | **对，确实没有**。每个会话各管各的 |
| 一天聊几十个人，晚上不会累 | **不太对**。睡前 20 分钟有【快到休息时间了】的犯困提示，钱快用完有【有点累了】。另外线上每天平均只有 18 次回消息，"聊几十个人"的情况还没出现过 |

**DS 的改法**：加 `energy` / `irritation` / `warmth` 三个会累积、会衰减的数，每轮多拼一句"你现在有点累 / 有点烦 / 心情不错"。

**看法**：想法有道理，"今天和昨天不一样"确实能让她更像真人。但要注意：

1. **这是一个新机制**：三个数怎么涨、怎么落、多少算"有点烦"，都要调，调法和好感档位一样要靠测试和线上数据。好感档位调了几轮，现在线上 42 人里 39 个还是陌生人，说明这类"累积的数"在这么小的用量下很难调准。
2. **提示里的词会被照搬**：这个项目反复出过"提示里写了什么她就说什么"的问题（"赶路""结巴""点明不熟"）。每轮加一句"你现在有点累"，很可能变成她句句喊累，压下去又要几轮。
3. **把烦躁带给下一个人，正是 DS 自己担心的"莫名冷淡"**：熟人什么都没做，她却带着刚才的火气。这一点要不要，需要你先定。
4. **和观察期冲突**：现在刚定下要停下来看线上。

**建议**：先不做。观察期后如果想做，从最窄的开始：只做"被同一个人冒犯后，接下来半小时对他冷一点"（只影响这个人，不串到别人身上），用回归测一轮再定要不要扩大。

## 3. 第三条：主动说的事不进记忆

**核对**（`proactive_group.py` 第 177～181、304 行，`proactive_private.py` 第 106 行）：

| 主动行为 | 进短期记忆（聊天记录） | 进长期记忆 |
|---|---|---|
| 插话 | 进这个群的记录 | 不进（代码里写明：不因为这一句给谁加减好感） |
| 冒泡 | 进这个群的记录 | 不进 |
| 写信 | 进对方的私聊记录 | 不进 |
| 冷场搭话 | 进对方的私聊记录 | 没逐行查，按《测试指令会不会留下错误记忆》第 3 节，也是只进聊天记录 |

所以 DS 说的"明天问她你上次说的猫呢，她接不上"**部分成立**：

- 当天、聊天记录还没被挤掉时，她接得上（群里留 10 条、私聊 20 条）；
- 群里聊过十来条以后，或者隔了几天，就接不上了，因为长期记忆里没有。

**看法**：值得做。"她说过的事她记得"对陪伴感确实重要，而记忆系统本来就有"她说过"一栏，专门记她讲过的旅途、答应过的事，冒泡和写信里编的小事正好属于这一类。

**要注意**：

1. **范围收窄**：冒泡、写信是她主动讲的一件事，适合进"她说过"；插话只是随口接一句，不用进。
2. **不能影响好感**：插话当初就是为了不加减好感才不进长期记忆的。现在有了测试模式那套"交给记忆但不打好感分"的写法，可以照着用。
3. **记忆 agent 花了很多功夫让"她说过"不塞满随口的话**（9/30 那几轮回放），加进来以后要跑一次记忆回放，看会不会塞满。

**建议**：观察期后做，归聊天 agent（主动说话的流程）+ 记忆 agent（整理时怎么收）。

## 4. 第四条：群里单线，B 的话被忽略

**核对**（`reply.py` 第 347～390、717～756 行，聊天规则第 4 条）：

- B 如果 **@ 她、叫她名字、回复她**，这条消息本身就会触发一次回复，**不是只进旁听**。`_hands` 这把锁让她一次只给一个人打字，B 的回复**排队等她回完 A 再发**（代码注释："排队等一等再回，而不是直接丢掉"），这时第一条会引用 B 的原话，免得大家不知道她在回哪句。这是 9/26 18:40 就有的。
- 旁听里有人点了她的名、问了她而她没回的，聊天规则写了"顺带答一下"（9/27 16:12 加的）。

所以"B 的话进旁听但不接"不对。真正的代价只是**慢**：B 要等她把 A 的话打完。

DS 提的"在回 A 的那条末尾带一句'对了 B，你刚才说的……'"，在 QQ 群里反而不如分开回、用引用标出回的是谁自然。

**建议**：不改。观察期里如果在日志里看到有人叫她、她却一直没回的，再单独查。

## 5. 第五条：语音没有情绪和关系

**核对**（`voice_chat.py` 第 64～67 行，语音服务 `elaina_tts.py`）：

- 按关系**发不发**已经有了：`voice_tier_multiplier`（讨厌 0、陌生人 0.3……很熟 1.5），DS 也提到了。
- **声音本身**确实不分情绪、不分关系：同一句话对谁都是一个调。
- 但现在的语音服务已经会**按句子挑参考音频**：问句用 r11、其他用 r8，"そう、私です"用原句当参考。GPT-SoVITS 的语气主要跟着参考音频走，所以"按情绪挑参考音频"不用等 TTS 升级，现在就能做：
  - 从 634 句训练素材里挑几段不同语气的（冷淡、得意、开心、不耐烦）当参考；
  - 按这条回复带的表情情绪（表情那边已经有 10 种情绪标签）或者关系选一段。

**看法**：成立，优先级也同意是低。语音只在你电脑开着时才有，用得也不多。

**建议**：观察期后，如果想让语音更有感情，交给语音 agent 先做一个小试验：挑 3～4 段不同语气的参考音频，同一句话各合成一遍，你听了觉得有区别再接进机器人。

## 6. 汇总：什么时候做

| 条 | 现在 | 观察期后的候选 |
|---|---|---|
| 一 | 不做 | 写信补"不想写就不写"（小改） |
| 二 | 不做 | 先定要不要；要的话从"只对冒犯她的那个人冷一点"开始 |
| 三 | 不做 | **冒泡、写信说的事进"她说过"**（最值得做） |
| 四 | 不做 | 不做 |
| 五 | 不做 | 语音按语气挑参考音频，先做试听 |
