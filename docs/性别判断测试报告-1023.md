## 3. 要知道的局限

1. **有些测试句就写在提示里当例子**："我要是男生就好了""下辈子想当女孩子""我男朋友今天来接我""我和我女朋友去看电影了"既是提示里的例子，也是测试题，第 3 轮全对有一部分是因为这个。没写进提示的说法（比如"我老婆今天加班""我前任……""我们宿舍都是女生"）没测过，线上碰到可能还会判错。
2. **temperature 0 也会有不同答案**：第 2 轮同一句"我女朋友今天来接我"3 次里 1 次对、2 次错。所以一句话判错一次不代表规律，要看多次。
3. **判错的后果不大**：认错成某个性别，她当轮会质疑一句"你说你是 X？"，显得突兀，但**不会记进档案**，要对方再确认才记一次"自称"；只靠自称也到不了很熟。认错成"否认"或"无"，就是这轮不管性别。
4. **只看这一句和她上一句**：更早的上下文不看。对方隔几句才确认（"对，我刚才说的是真的"），可能认不出来，会等 30 分钟后"待确认"自动作废。

## 4. 部署以后怎么看

- 日志里每次问模型会记一行"性别：模型判断 QQ号 这句是‘…’：原话"，判断出错会记"性别：判断出错，这轮不管"。
- 部署后过几天拉一次日志，把这些行挑出来看有没有判错的；有就把那句加进 `tools\gender_judge_test.py` 再测、再改提示。
