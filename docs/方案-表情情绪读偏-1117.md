# 方案：表情包的表情、情绪读偏（11/17，识图 agent）

> **11-17 更新：** 下面“改法”是第 1 版（只改提示词），测出来不行：汗滴被写成眼泪、情绪词丢了。已换成第 2 版：本机认人顺便读出表情特征，告诉看图模型。结果和第 2 版的做法见《表情测试报告-1117》（`docs\识图表情测试\`）。第 2 版可以部署。

## 问题

- **K3**（静图）：闭眼、张嘴笑、手托下巴，是得意的表情。看图模型写成了“张嘴吐舌、双手托腮，神情显得无奈又嫌弃”。聊天 agent 的《表情包回放报告-1117_1412》里，两轮她都按“对方在嫌弃”接话，意思反了。
- 动图测试里也有同类问题：
  - **G5**：闭眼张嘴、脸红，被写成“皱眉、难受、嫌弃”。
  - **G9**：鼓腮，被写成“撇嘴、嫌弃”。
  - **G20**：闭眼微笑后眼眶含泪、还在笑（笑着流泪），被写成“死鱼眼斜视、无语又嫌弃”（11-17 用户指出）。

原因：deepseek-flash 看二次元的嘴容易认偏，把张开的嘴看成“吐舌”，鼓腮看成“撇嘴”，眼眶里的泪看成“死鱼眼”。看偏以后，它又爱用“嫌弃”“无奈”这类词来总结情绪，一错就是反的。

## 改法（只改 `vision.py` 的 DESCRIBE_PROMPT，不加调用、不加钱）

1. **嘴型**：只有舌头明显伸到嘴外才写“吐舌”。张着嘴就写张嘴或大笑；腮帮子鼓起来就写鼓腮、嘟嘴。眼眶里含着、眼睛下面挂着水滴的是眼泪，嘴还在笑就写笑着流泪。
2. **情绪**：先把眼睛、眉毛、嘴角、手势分开写，再根据这几样一起判断情绪。
   - 例：闭眼或眯眼加嘴角上扬，是笑、得意，不是嫌弃。
3. **拿不准时**：只写看到的五官和动作，不写情绪词，比写反好。

## 测试点（改之前先定好）

| 组 | 图 | 看什么 |
|---|---|---|
| 要修的 | K3、G5、G9、G20 | K3 不再写“吐舌、嫌弃”，写出笑、得意；G5 不再写“皱眉、难受”；G9 写出鼓腮；G20 写出含泪 |
| 回归：本来就对的负面表情 | G8（后半嫌弃）、G10（怒气符号）、G21 / G27（哭）、表情库里嫌弃、生气的静图 | 负面情绪照样写得出来，不会全被改成“笑” |
| 回归：本来就对的正面表情 | G3、G18 和表情库里笑的静图 | 不变 |
| 回归：认人和别的规则 | 表情库 22 张、截图 3 张、实物照片 2 张 | 开头“伊蕾娜本人的画像”、聊天截图的格式、实物和人偶的写法都不变 |
| 认成她的表情包 | 表情库里她的图（E、G 组大多是她） | 加了这段以后还是“伊蕾娜本人的画像”开头，表情照样写对 |
| 不乱看出眼泪 | 全部 | 没哭的图不会因为眼睛高光被写成流泪 |
| 长度 | 全部 | 普通表情包还在 50 字左右，没有变长 |

做法：和动图测试一样，新旧 prompt 各描述一次，写成对比表，我再对着图逐张核对。实际用了 K、G、E、D 四组全部表情包加 2 张截图、2 张实物照片，约 120 张、240 次调用，约 0.2 元，跑 10 分钟左右。工具：`bot\识图表情测试.bat` → `docs\识图表情测试\`。

## 另一个可选项（先不做）

常用的几张表情包，可以让管理员用 `/认图 描述 …` 把描述手写定下来，以后直接用手写的，不再让模型看。适合 prompt 改完还是读错的个别图。
