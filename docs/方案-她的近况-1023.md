## 1. 为什么这样做

- 真实的好友，生活你看不见，只有你问起或者她想说时才听到一句。重点是**她说过的事她记得、前后对得上**，而不是她的生活里一定要发生事情。
- 现在的问题是她说过就忘：冒泡、写信、搭话、聊天里讲的"最近遇到的事""我现在在哪"，只进那个会话的聊天记录，挤掉就忘了；不同地方还会讲出几个版本。
- 程序去模拟一个世界（路线、事件、好坏比例）会让聊天的重心变成"她今天又发生了什么"，那是酒馆的做法。

## 2. 记什么、不记什么

| 记 | 不记 |
|---|---|
| 她讲成"自己最近经历"的事 | 小说里的往事（在知识库和"她说过"里） |
| **她说自己现在在哪**（到了某个镇、在森林里赶路、又回到小说里去过的某个国家……）| 玩笑、比喻、假设 |
| 来源：冒泡、写信、冷场搭话发出去的话，正常聊天里她讲的经历 | 和某个具体的人有关的事、私聊里对方的事 |
| | 插话（随口接一句） |

**"现在在哪"从她的话里来**：

- 她说了"到了某个镇""这几天都在林子里赶路"，就更新成现在在那里，记下从哪天开始。
- 她是旅行魔女，换地方很正常：说"今天到了……"就是换了地方。
- 没有讲到换地方、又和现在在哪对不上的（上午说在镇上，下午随口说在森林里），先不更新，也不记那条，日志里记一行。
- 回到小说里去过的地方可以，记的是这次的事，不是当年的事。
- 一开始没有"现在在哪"，等她自己说了再有。

**会漏掉怎么办**（10/23 用户同意补的）：

- 可能漏的情况：说得太随意没认出来；正常聊天要等整理（私聊安静 10 分钟、群 15 分钟）才记上；插话、测试模式本来就不记。反过来也可能记错：她讲往事"以前在某某国"被当成现在在那。
- 漏了最坏也就是她下次随口说个别的地方，和现在一样；记上一次以后每轮都给她看，她会顺着说，越用越稳。
- 补两处：
  1. **还没记上时告诉她**：没有"现在在哪"时，【你的近况】里写一句"你还没说过自己现在在哪"，被问起就随口说一个，说了就会记下来。
  2. **记得太久了加一句提醒**：说在某处以后过了几天（建议 5 天）没再提，给她看的是"前几天说在某处，现在不一定还在"，她可以自然地说已经离开了。
- 记忆回放专门数一下"现在在哪"认得对不对（见第 5 节第 5 条）；漏得多再考虑加快：她的回复里出现"到了""在……镇""森林里"这类词时，不等整理，马上单独认一次。
- 记错了用 `/近况 改` 手动改。

## 3. 怎么用

| 场合 | 给她看什么 |
|---|---|
| 平时回消息 | 每轮一小段【你的近况】：她说过自己现在在哪 + 最近说过的一两件事 + 按对方这句话挑的一两条，100 字左右。写明：这些是你自己说过的，被问起照着说、别另编；**不用主动提** |
| 冒泡、写信、冷场搭话 | 带最近几条和"这里已经讲过的"。有近况可以接着讲，也可以说一件新的，但别和近况对不上；这里讲过的别再讲。没有合适的照旧自己说一件小事（说了就会被记下来） |
| 有人问起她以前说过的事 | 查得到照着说；查不到按现在的规则"记不清就说记不清" |

## 4. 要防的

1. **滚雪球**：面包、钱、蘑菇这类条目限量（记忆 agent 已经定了：存的时候两周内最多 3 条，取用时对方没提最多带 1 条）。
2. **变成话题中心**：规则里写"不用主动提"，回归测试里数她在不相关的闲聊里提近况的次数。
3. **编的事变成包袱**：只记她认真讲成"我遇到了……"的事，分不清的不记。
4. **测试模式**：管理员 `/测试` 开着时，他的对话本来就不进整理（《交接》第 5 节）。
