# 伊蕾娜发语音：克隆方案

> 编写：2026-10-19 晚（聊天 agent）
> 状态：第 0 步（发送通道）**已部署、测试通过**；其余还没开始，等素材。

---

## 1. 已经定下来的

| 项 | 决定 |
|---|---|
| 还原度 | 越高越好，个人使用，可以克隆原声 |
| 在哪合成 | **你电脑的 RTX 4060（笔记本，8G 显存）**。服务器只有 2G 内存、没有显卡，跑不动 |
| 说什么语言 | 先都试：同一个模型分别生成"日语原声说中文"和"直接说日语"的样音，你听过再定 |
| 素材 | 你去找广播剧等资源（要求见第 3 节） |

## 2. 整体怎么跑

```
QQ ← NapCat ← 机器人（服务器）
                 │ 要发语音时：POST http://127.0.0.1:9880/tts
                 │（这个端口是一条 SSH 反向隧道，另一头在你电脑上）
                 ▼
         你的电脑：GPT-SoVITS 的 api_v2（4060 合成，一句约 1 秒）
```

- **模型**：GPT-SoVITS，用 v2Pro / v2ProPlus 这一代。官方说明里它们的效果比 v4 好，显存和速度跟 v2 差不多，8G 显存够训练也够合成。支持中、日、英等语言，训练用日语素材，合成可以说中文（跨语种）。
- **连接**：你电脑开一条 SSH 反向隧道连到服务器（`ssh -R`，用现在登录服务器的那把密钥）。这样服务器上的机器人访问自己的 9880 端口，就等于在调用你电脑上的合成服务。
  - 不用在阿里云开任何端口，也不用公网 IP；隧道只在服务器本机能用，外面访问不到。
  - 断了会自动重连。到时候我写一个 `启动语音服务.bat`，双击后同时开合成服务和隧道。
- **电脑关机、睡眠、隧道断开时**：她照常只发文字，不报错、不提示，聊天不受影响。所以她"有时会发语音"，前提是你电脑开着。
- **花费**：合成不花钱，DeepSeek 的钱也不多花（这一轮回复本来就要生成）。服务器内存基本不增加。

## 3. 素材要求（你去找的时候看这个）

**要多少**：
- 最少 1 分钟就能训练，但还原度一般。
- **建议 10～30 分钟干净的、只有她一个人的声音**，效果最好。
- 超过 30 分钟提升就不明显了；更重要的是"干净"，脏素材多了反而拉低效果。
- 找到的原始素材可以多一些（比如一两个小时），要剪掉别人说话、背景音乐，最后剩下的才算数。

**什么样的好**：

| 好 | 不好 |
|---|---|
| 广播剧、角色语音、旁白：只有人声、没有背景音乐 | 唱歌（角色歌、OP/ED）：完全不能用 |
| 正常说话，语气多样一点（得意、嫌弃、平静、吐槽都有） | 一直在喊、哭、尖叫的片段 |
| 原文件音质好（flac、wav、高码率 mp3） | 视频网站压缩过的、有混响、有回声的 |
| 动画正片也行（她有大量旁白），但要先去掉背景音乐 | 多人同时说话、互相抢话的段落 |

**格式**：音频、视频都可以（mp3、flac、wav、m4a、mp4、mkv……），不用你先转。

**放哪**：在 `D:\QQBot` 下面新建一个 `voice_data\原始素材\` 文件夹，把文件丢进去，按来源分子文件夹就行（比如 `广播剧1\`、`动画\`）。这个文件夹会加进 `.gitignore`，不上 GitHub。

## 5. 要注意的

- **模型和素材不上 GitHub**：`voice_data\`、训练出来的模型文件、参考音频都放在 `.gitignore` 里。
- **电脑睡眠**：Windows 默认插电一段时间后会睡眠，睡了她就不发语音了。想让她一直能发，要把"插电时睡眠"改成"从不"（到第 6 步再说）。
- **4060 笔记本的显存是 8G**：训练时把批大小调小、打开半精度（fp16），到时候我会写具体数值。合成时一般占 3～4G，你同时打游戏可能会抢显存。
