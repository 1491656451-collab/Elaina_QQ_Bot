## 2. 22:51 再改了什么

问题出在“范围”：写 +1～+2，模型就给 +1。所以这次改成**每档一个数**，并且写明“聊得还不错的一段，一般就给 +2”：

| 改前（10/22 以前） | 22:44 版 | **22:51 版（现在）** |
|---|---|---|
| +1～+5：聊得投机、有趣、尊重她、真诚关心她…… | +1～+2：正常聊得愉快、有来有往（聊得久的给 +2） | **+1**：聊了几句、还算客气，但没怎么聊起来 |
| 0：普通寒暄、没什么感觉 | +2～+3：聊得投机、真诚关心、记得她的喜好 | **+2**：正常聊得愉快、有来有往、尊重她（聊得还不错的一段，一般就给 +2） |
| | +4～+5：只给特别打动她的事，很少给 | **+3**：聊得投机、有趣，真诚关心她，记得她的喜好…… |
| | 0：只是寒暄、问一句答一句 | **+4～+5**：只给特别打动她的事，很少给；**0**：只是寒暄 |

- “她是慢热的人……别因为谨慎只给 +1，也别随手给 +4 以上”这句留着。
- 扣分那几行、普通朋友 / 熟人 / 很熟 / 讨厌那几行，都没动。
- 程序测试 334 个全过，已经写回电脑上的 `memory.py`。

**预计**：这次真实聊天里的 +1，多半会变成 +2，“还算客气但没怎么聊起来”的留在 +1。加分平均大概会在 1.5～2 之间。要是超过 2.5，或者只是寒暄的也开始给 +1、+2，我再往回收。
